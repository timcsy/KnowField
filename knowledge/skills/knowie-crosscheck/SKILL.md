# 跨 base 判準量測

**為什麼存在**：使用者有十幾個專案、上千條教訓，而**看不到複利**——
開新專案還是冷啟動。這支東西把「哪些判準是**幾個獨立的場各自撞出來的**」找出來，
因為那正是最值得帶走的：它已經被獨立驗證過好幾次。

實測（2026-08-27，13 個 base／1,393 條）：跨 base 群 **49 個／157 條**，跨 ≥3 個的 **16 群**。
⚠️ 其中三群是 KnowField **當天才學會**、而 VizGPT／semorphe **早就寫下來**的
——複利的成本不是抽象的，是那天有好幾個小時花在重新發現。

## 判準：**沒有校驗過的門檻，給的不是空結果，是錯結果**

第一次跑用了 0.78（「常見的語意相似門檻」），得到的結論是
**「幾乎沒有複利」**——聽起來像個發現，而且完全錯。

拿一對**你知道是同一條**的句子餵進去（`沒有東西會叫的失敗` ↔ `沉默的失敗不會自己現形`），
它只有 **0.581**；而隨機跨 base 配對是 0.27–0.42。⇒ 真門檻在 **0.62** 附近，
不是 0.78。差這 0.16，結論從「49 群」變成「沒有」。

**所以校驗配對是人給的，而且不給就不出結果**（`crosscheck.py` 直接 exit）。
兩個獨立的人各自寫下同一條判準，用字幾乎不會重疊——這件事**沒有先驗值可以查**。

### ⚠️ 而校驗配對只給你**下界**

第二次跑才發現：校驗分數 0.617、噪音上緣 0.561 ⇒ 「建議門檻」算出 0.59，
而 0.59 產生了**一群 178 條**——好幾個判準被一條條邊**串**成一坨。

| 門檻 | 群數／條數 | 最大一群 |
|---|---|---|
| 0.59 | 62／337 | **178** ← 黏成一坨 |
| **0.62** | **49／156** | 20 |
| 0.65 | 30／71 | 4（但少掉一半） |

**校驗配對定的是天花板**（高過它就真的漏），**連通分量的串連定的是地板**。
兩邊都要量——只量一邊就會像我第一次那樣，拿著一個看起來有理的數字得到錯結論。
⇒ 每個門檻都跑，看 `最大一群` 那行，取**不黏**的最高值。

## 步驟

```bash
# 1. 先只看數字（不帶 --threshold ⇒ 它會拒絕給群）
uv run python knowledge/skills/knowie-crosscheck/crosscheck.py ~/Documents/Projects \
  --calib "沒有東西會叫的失敗|||沉默的失敗不會自己現形"

# 2. 看噪音帶與校驗分數，門檻落在兩者之間，再跑一次
uv run python knowledge/skills/knowie-crosscheck/crosscheck.py ~/Documents/Projects \
  --calib "沒有東西會叫的失敗|||沉默的失敗不會自己現形" \
  --threshold 0.62 --out /tmp/crosscheck.json

# 3. 貼進 KnowField 的「💡 你的理解 → 🛬 從別的知識庫來的判準」，或直接送
curl -s localhost:8001/api/borrowed/import -H 'Content-Type: application/json' -d @/tmp/crosscheck.json
```

## 三個會安靜出錯的地方

- ⚠️ **離線 embedding stub**：256 維雜湊向量，**會跑完、不會報錯**，相似度全是噪音。
  已在 `crosscheck.py` 擋掉（`OpenAIEmbedder` 以外一律拒絕）。
- ⚠️ **recall 有限**：那對 0.581 的真配對，**任何合理門檻都抓不到**。
  所以輸出是**複審佇列**，不是「全部的複利」——別把它當成完整清單報告給人。
- ⚠️ **相似度是篩子，不是判準**。0.62 把 1,393² 降到十分鐘看得完的 49 群，
  接下來哪條算數是**人在收件匣一條一條決定**的——所以匯入端**不顯示分數**。

## ⚠️ 借來的不算一次「撞到」

`lessons()` 會**跳過**內文帶 `⚠️ **借來的**` 的教訓——它們是 [knowie-pull](../knowie-pull/SKILL.md)
從別的 base 拉進來的，**在這個 base 真的撞到之前不算這個 base 的經驗**。

不跳過的話：pull 寫進去 → 下次量測讀成「這個 base 也獨立撞到了」→ 計數餵回推薦、
推薦餵回計數 ⇒ **馬太**。draft §八 的原話：「只算『撞到』，不算『借走』。」

⇒ 所以標記由 `emit_lesson()` 產生、`lessons()` 讀，**共用 `BORROWED_MARK` 一個常數**：
各寫一份字串遲早會不一致，而**不一致不會報錯**，只會讓數字慢慢變大。

## 界線

這支只**算**與**輸出**。收下與否是人的事，走 KnowField 收件匣（spec 071），
一條一條，`origin` 標成 `from:<bases>`——**在這個場真的撞到之前，它不算你自己撞出來的**。
