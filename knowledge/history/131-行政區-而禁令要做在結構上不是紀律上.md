# 131：行政區——而禁令要做在**結構上**，不是紀律上

- 日期：2026-08-27 · spec：[069](../../specs/069-districting/) · 階段：vision 階段 63

## 轉移

| | 之前 | 之後 |
|---|---|---|
| 領域怎麼來 | 人手動建、手動搬（正式庫因此只有 1 個） | **機器劃、人逐區核准** |
| `domain_id` | 「你放的」 | 「你的**地址**」（＋ `assigned_by` 分得出是誰放的） |
| 分群依據 | 既有的邊（spec 065） | 既有的邊 ＋ **相似度** ⇒ 涵蓋所有東西 |

## ⚠️ 這一刀最重要的決定：禁令做在結構上

實驗（2026-08-26，正式庫 117 節點）：換個隨機種子分區就大幅重排，**ARI ≈ 0.18**。
⇒ 「哪天重跑一次」會讓大量地址改變。

第一個念頭是寫一條規則：「不要全量重劃」。**但規則會被忘記。**

⇒ 改成：劃界**只讀 `domain_id IS NULL` 的東西**。
於是「動到已經歸屬的東西」**不是被禁止，是沒有那條路**。
對抗驗證：把那個過濾拿掉 → 測試立刻紅。

ⓘ 同一個形狀在這個庫裡出現過：spec 065 的「沒有全部套用」也是——
不是「不要按」，是**那個 API 不存在**，而且有一支測試掃路由表守著它不會出現。

## 位置的取法本身是一個設計決定

互動用**它冊封出的理解的重心**、應用用骨幹理解的重心。
⚠️ 這不只是省一次 embedding 呼叫：**互動的位置由它產出的理解決定**，
比拿標題去 embed 更貼近它實際在講什麼——一段互動的標題常常只是第一句問話。

而**同種＝相似度（地形）· 跨種＝真實關係（道路，權重更高）**。
硬理由：異質節點的相似度不可比（40 則的互動 vs 一句理解 vs 一塊來源文字）。
順帶得到冗餘：相似度爛掉時，道路還在。

⚠️ 維度不一致直接放棄整個劃界。實驗時差點把 256 維的離線 stub 混進 1536 維的真實向量
——那會算出**看起來完全正常的垃圾距離**。

## 泛詞要擋，不能只在 prompt 裡講

第一次跑出來的區名有「AI」。⚠️ 那是分群命名的經典退化：
LLM 最省力的答案永遠是**共有的最泛的詞**。

判準（就是 knowie 判斷真／假母概念的同一把尺）：
**一個名字如果可以套在任何一群上，它就沒有修剪力。**
⇒ 加了黑名單擋掉，擋掉就退回錨。修正後跑出來的是
「資料幾何結構」「cyber resilience」「層級式維度」「Agent security」「LLMs training」。

## 措辭也是設計的一部分

介面**不能說**「這是你的行政區」——那會讓一個 ARI 0.18 的結構看起來像客觀結果。
說的是：**「這是一個劃法，不是唯一的劃法——改到你認可為止。」**
