# 148：專案就是來源——**而三種攻擊沒撞紅，因為測試在掃字串**

- 日期：2026-08-27 · spec 080（階段 71 第二刀）· 相關：
  [147](147-聊天一直沒吃領域-而那個洞開了十九階段.md)（第一刀）

## 做了什麼

專案的知識檔**逐檔落成來源**（`github://owner/repo/knowledge/x.md`），
走既有的 `_ingest_markdown` ⇒ 切塊、嵌入、去重、進語料**全部免費**。
歸屬**跟抓取同時發生**（一個專案一個領域）。

實跑：knowie **61 個檔 → 825 個塊，全部歸在「knowie」領域底下**；
不縮範圍時 1,486 筆語料 ⇒ **跨專案是免費的**。

⇒ spec 076／078 的「兩個場」與 spec 077（寫回 draft）**退役**。

## ⚠️ 三種攻擊沒撞紅，而原因是同一個

我第一版的測試是**掃原始碼**（有沒有寫 `ContentIngestService`、`set_knowledge_domain`
在不在 `if` 外面、url 格式對不對）。而三種攻擊——
**只在新收時歸屬** · **前綴放寬** · **不走共同出口**——**一種都沒紅**。

⇒ **掃描器看得到「有沒有寫那個字」，看不到「它做了什麼」。**

改成把 GitHub 那一層樁掉、真的跑一次落庫之後，四種攻擊全紅。

⚠️ 判準：**當一條測試的斷言是「原始碼裡有這個字串」，先問「改壞它的最短方式會不會留下那個字串」。**
會 ⇒ 那條測試守不住任何東西。
（掃描器仍有它的位置——守**結構性禁令**：「這個字**不准**出現」。守「有做到」時它就是空的。）

## ⓘ 而其中一種攻擊我自己也打錯了

「前綴放寬」我寫成 `prefix[:22]`，而 `github://timcsy/Demo/` **只有 21 個字元**
——那個攻擊**什麼都沒改**。換成 `prefix.rstrip('/')`（`Demo` 會吃到 `DemoTwo`）才紅。

⇒ **一種攻擊沒撞紅時，先確認那個攻擊真的改到了東西**，再去懷疑測試。

## ⚠️ 實跑抓到：狀態在做完之前就說 ok

`save_ext_fetch` 把狀態設成 `ok`，而**落成來源還沒開始**。我因此查得太早，
看到「1 個檔、歸屬 0 筆」，一度以為功能壞了。

⇒ 「[工具回報「成功」不等於它做到了](../experience.md)」的第二次現身，這次是我自己寫的狀態。
補了 `indexing` 這個中間狀態，`ok` 只在**全部做完之後**才設。

## 順帶：一個藏了很久的同名方法

`Repository` 有**兩個 `delete_source`**——刪訂閱來源（`sources` 表）與封存收進的來源
（spec 055）。後定義的蓋掉前面的，⇒ **前面那支從那天起就到不了**。
兩個呼叫點都傳 url，所以沒有人踩到；**但那是運氣，不是設計**。

⇒ 判準：**同一個類別裡出現同名方法，那不是重載，是其中一支已經死了。**
改名為 `delete_feed`，並加一條 AST 掃描釘住「不准有同名方法」。

## 而收尾時把「兩個場」整個拆掉了

樹改讀來源（FR-004）之後，spec 076／078 的第二個場**沒有存在的理由了**：
`ext_chunks` 一套語料、`_ASK_MIN = 0.35` 一套門檻、`/ask` 一支問答、
`ext_base_id` 一條聊天分支——全部只是「同一件事的第二份實作」。

⇒ 刪掉，不是停用：`_chat_corpus` 的第二分支、`/index`／`/corpus`／`/ask`／`/draft`
（spec 077）、`ext_tree`／`ext_layer_items`／`ext_item` 路由，以及 `github/draftout.py`。
`ext_chunks` 與 `conversations.ext_base_id` 兩張表／欄留著，
**只為了清得掉正式庫的舊列**，並在 schema 上寫明沒有人再寫它們。

⚠️ 判準：**兩份實作做同一件事時，它們一定會漂，而漂掉的那一份不會報錯。**
它只是慢慢答得跟另一份不一樣，而你以為你在看同一個系統。

ⓘ 順帶治好一個更廣的洞：「你還沒存下自己的理解」那句話**不是專案專屬的**
——`roots` 被**任何**窄領域濾空都會發生。所以「你站在哪」現在掛在 `domain` 上，
互動模式的領域選單也一起修好了。

## ⚠️ 第五種攻擊改到了東西，測試卻沒紅

「預覽回頭讀快照」——我確認過那個攻擊真的改了程式，測試仍然綠。
原因是**兩條路徑的產物一模一樣**：測資裡快照和來源是同一份文字。

⇒ 這是上面那條的另一半：攻擊生效了、測試也在跑行為，
但**兩邊分不出來**。修法是讓來源帶一句快照沒有的話（`ONLY_SOURCE`），
並拿一份**只存在於來源**的檔（`skills/x/SKILL.md`）當第二個證人。
