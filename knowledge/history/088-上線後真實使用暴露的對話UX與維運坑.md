# 088：上線後真實使用（手機）暴露的一批對話 UX 問題與維運坑

> 日期：2026-08-08。承 `history/087`（首次上線 know.tew.tw）。使用者在**手機**上真的用起來後，一連串問題浮現、
> 逐一修。價值：**上線＋真實使用（尤其手機）是最強的缺陷照妖鏡**——本地/桌面/測試都照不到的，一用就現形。

## 一、對話生命週期真 bug：接回已存檔對話繼續聊會分岔（`7a97b48`）
- **現象**：在已存檔（永久）對話上繼續聊，會另開一筆**暫存**；「promote 後又突然變回暫存」也是同根源。
- **根因**：autosave `UPDATE … WHERE id=%s AND temporary=1` ＋前端 resume 永久對話時 `tempId=null` → 繼續聊 autosave
  拿 null → INSERT 新暫存。
- **修**：autosave 去掉 `AND temporary=1`（**就地更新同一筆**、保留永久/暫存狀態）；前端 resume 一律綁該對話 id。
  → 升 experience「upsert 綁實體 id、別綁狀態旗標」。

## 二、串流中數學/格式沒渲染（`2d81…`）
串流回覆原本是 raw text（`whitespace-pre-wrap`）→ 數學要等訊息完成換 `<Markdown>` 才被 MathJax 渲染。
修：串流也走 `<Markdown>`（與完成訊息同路徑），公式邊串邊渲染（未閉合 `$$` 留 raw 到收尾）。

## 三、對話刪除＋⋮ 選單＋引用保護（`… delete`）
- 側欄/總對話頁改 SOTA **⋮ 選單**（檢視/接著聊/改名/轉永久/刪除）。
- **刪除引用保護（護溯源，原則 3）**：被核心理解引用（why_node.conversation_id）的對話**刪不掉**，回 `blocked_by`＝
  那些核心理解主張，提示先刪它們。repository `conversation_referrers`＋`delete_conversation`；API `/api/conversations/{id}/delete`。

## 四、手機選單友善（`… mobile`）＋⋮ 選單被裁切（`… portal`）
- 手機無 hover → ⋮ 原本 `opacity-0 group-hover` 看不到。修：⋮ 手機常駐、點擊區加大、**長按對話開選單**。
- **暫存的 ⋮ 點不下去**＝選單被側欄 `overflow-y-auto` 裁切。修：抽共用 `ConvMenu`＝**portal 到 body＋fixed 定位**
  （不被任何容器裁切）、靠底自動往上開、捲動即關。側欄與總對話頁共用。→ 升 experience。

## 五、送出聊天沒即時顯示使用者訊息（`… optimistic`）
`send()` 只在 `onDone` 才把使用者訊息加進 messages → 送出後只見「思考中…」＋串流回答，自己那句要等回答完才出現。
修：捕捉 hist 後立即 `setMessages([...hist, 使用者訊息])`（樂觀更新）。→ 升 experience。

## 維運事件（真實使用中發生，值得記）
- **遷移漏搬 media**：`history/087` 只遷 DB、**漏了 media/ 圖片與 PDF（55 檔 32MB）** → 使用者看到「資訊不見了」（破圖/無預覽）。
  補：`tar cf - -C media . | kubectl exec -i pod -- tar xf - -C /data/media`。→ 教訓：**遷移要含 DB 以外的檔案**。
- **手機 PWA 舊 SW 卡住**：使用者按「轉永久」的請求**根本沒到伺服器**（log 無 promote），是手機 PWA 跑舊快取前端。
  桌面可 DevTools 清 SW，手機只能完全關 app 重開/移除重加。#28 我直接在 DB 轉永久解圍（資料一直安全＝自動暫存＋PG 墊著）。
- **在使用者線上使用時 rollout**：我為修 proxy-headers 做 rollout，可能讓 in-flight 請求掉。→ 教訓：**別在使用者線上用時部署**。
