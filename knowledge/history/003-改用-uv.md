# 003：套件/環境管理改用 uv
> 日期：2026-07-23

## 轉移
- 舊：文件以 `pip install -e .` 為安裝方式（見 002 實作階段）。
- 新：以 **uv** 管理環境與相依——`uv sync` 建立 `.venv`＋`uv.lock`，`uv run` 執行
  測試與 CLI。`docs/usage.md` 改用 uv 指令。

## 為什麼變
使用者偏好 uv（更快、lockfile 可重現、免手動啟用 venv）。`pyproject.toml` 原本即標準
PEP 621，uv 直接沿用，未破壞既有結構——屬純工具鏈約定，不影響架構或程式碼。

## 影響
- 新增 `uv.lock`（納入版控）；`.venv` 由 `.gitignore` 排除。
- 可選後端仍為 extra：`uv sync --extra backends`（真實 embedding/LLM）；
  dev 用 `uv sync --extra dev`（pytest）。
- 驗證：`uv run pytest` → 49 passed；`uv run learnnews` script 進入點正常。
