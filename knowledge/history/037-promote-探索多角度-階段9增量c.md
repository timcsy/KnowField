# 037：promote 探索（多角度 a）→ vision 階段 9 增量 c

> 日期：2026-07-25　｜　承接 history/036（智慧搜尋完成）

## 轉移
智慧搜尋（增量 b）完成後，使用者選做 draft 裡孵化的**探索**。探索有**成本分叉**，先 AskUserQuestion
釐清深度 → 使用者選 **(a) 多角度擴展**（非 (b) agentic）。promote (a) 成 **vision 階段 9 增量 c**。

## 決策
- **(a) 多角度（本增量）**：LLM 拆 query 成 3–5 子角度 → 各搜一次 → 合併去重 → 對合併池跑
  **現有整理**（spec 010）。**單輪、有界、成本可預測。**
- **opt-in 預設關**：`/search` 加「深入探索」開關；不開＝增量 b 行為。**貴的只在使用者要時才花**
  ——直接服務根公理「跟上趨勢的成本要極低」。
- **(b) agentic 追線索**：多輪迴圈、難預測 → **optional／未 promote**，留更後面拍板。

## 為何這樣切（三面對齊）
- **principles**：根公理成本極低 → opt-in＋子角度上限＋單輪；原則 3/4/5 沿用增量 b（整理 grounded、
  可回溯、人挑）。
- **experience**：教訓 1（查詢擴展後端要離線 stub 可測）、教訓 3（擴展失敗退回單 query）。
- **concept**：`有吸引子的場` 的**反濾泡/驚訝力**再進一步——撒更廣的網照到單一 query 的盲區。
- **復用**：合併去重後**直接餵進 spec 010 的 SmartSearch 整理管線**，只在前面加一層 fan-out。

## 其他路線（否決／擱置）
- 直接做 (b) agentic：貴、慢、難預測、違成本根公理 → 擱成 optional。
- 多角度預設開：會讓每次搜尋都翻倍成本 → 改 opt-in 預設關。
