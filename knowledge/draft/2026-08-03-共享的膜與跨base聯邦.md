# 共享的膜 ＋ 跨 base 聯邦（knowie 前端的未來方向）

> 狀態：**draft／未定案設計（thinking-line）**。日期：2026-08-03。全是**發想**——外推一道**還沒蓋、還沒驗**
> 的膜，先當假說。成熟出口＝**vision 路線圖（要人 commit 才升）**；在那之前不進三大檔。

## 起點：工具收斂成 knowie，chat+websearch 是原子單位
1. 使用者想砍掉一堆進料/新聞分診的舊功能（轉向前的殘骸）。砍完剩下的核心＝`跟知識聊`→`根因`→`對話存檔`，
   **骨架本來就是 knowie 形狀**（根因=principles、暫存/永久=draft/episodes）。
2. 關鍵洞見：**「chat-only 發想 ＋ 要 AI 查 web」就是使用者工作的原子單位**（他連跟我 chat-only 都在做這件事）；
   其餘功能都是繞著它的鷹架。KnowField 的 `/chat` ＝這件事的**有紀律版**（有膜、有捕捉、有場 grounding），
   Claude Code 裡的 chat-only ＝**原始版**（無膜、會蒸發、不 grounded）。
3. 願景（未定案）：一個**聯邦多個 knowie base ＋個人場**的前端，讓資訊成為**共享知識**。
   - **膜頂回**：不是「讓 KnowField 長得像 knowie」，而是「把使用者本來就在做的那件事，給它一個**同時有紀律
     （膜）又可攜（knowie markdown）**的家」。
   - **分階**：先聯邦**自己的** base（單一把關、純度可控）；**跨人共享**是研究等級難題、先當北極星別當 sprint。

## 設計：共享的膜（跨 base）
生成根：**單一 base 的膜讓「你對自己」誠實；共享的膜讓「base 對 base」誠實——但絕不塌縮成共識。**
工作＝**讓分歧可讀、讓出處透明，不是製造同意。**
- **出處向量**：每條主張帶「在 A 的經驗層 grounded、在 B 沉默、跟 C 矛盾」，不再只是 grounded/猜。
- **矛盾是訊號、絕不平均**：跨 base 矛盾要**主動獵取、攤開、分類**（尺度不同／開放問題／有一個錯），不揉成共識。
- **反權威洗白**：A 的 bedrock 到 B 只能當**提案/猜**，得經 B 的膜獨立 ground（反逢迎的群體版）。
- **共享根因＝撐過每個 base 各自的把關**（像定理在多套公理系統各自可證），**不是投票**；門檻更高、非妥協平均。
- **權能分立（來自神學三職分，見下）**：挑戰／維持／決斷三功能**分立且互檢**，別讓一個 base/人一手包。

## 規模化的湧現（好壞是同一台機器）
- **好**：跨場橋接根因（撐過多 oracle 的不變量）、矛盾地形（＝前沿地圖）、共享免疫（幻想沒法不被獨立驗過就傳開）。
- **壞**：共識引力（多數即真理、壓死可能對的異議）、接地通膨（grounded-once-沒人重驗＝引用洗白）、
  出處崩塌（鏈長到沒人追＝溯源劇場）、單一栽培（追共享根因餓死在地 novelty）。
- **皇冠**：給你橋接根因/免疫的那條「撐過每個膜」規則，同一條在規模下就長成共識引力/單一栽培。
  **免疫系統＝自體免疫的風險，同一台機器。→ 真正的設計問題：怎麼讓免疫不殺死還沒兌現的 novelty（＝保護異議）。**

## 四透鏡交叉盤問（brainstorming scene：why 的 why）
用「撐過多個獨立 oracle」的方法驗設計原則自己。每個透鏡：**貢獻一個機制 ＋ 標出它在哪裡騙人。**
- **生物（免疫/細胞膜）**：主動運輸（純度燒能量、停了＝熵＝那些失敗）／先天+後天雙臂（快通用膜＋慢特異冊封）／
  免疫記憶（**傳抗體=為何X錯，不只傳根因**）／**雙訊號 costimulation（升 bedrock 要「同意＋grounding 理由」兩訊號，
  單訊號→容忍不 commit ＝擋共識引力）**／**Treg（專職保護 novelty）**／自體免疫-過敏-免疫缺陷＝診斷詞彙。
  **騙人處**：免疫優化「自己/非己」，知識要優化「真/假」——正交。照抄＝排外＋自我崇拜（拒外來真、護native幻想）。
- **社會學**：偏好造假（**把異議變便宜**）／馬太效應（grounding 逐條重賺、不繼承聲望）／泡泡vs迴音室（兩種病兩種藥）／
  制度俘獲（閘門＝機制非權威）／組織化懷疑（**制度化的挑戰、指派 skeptic**）／證言（**信任但標記**、不可能每條都驗）／
  **認知分工（結構性資助少數派＝Treg 的社會版）**／**邊界物件（共享物件、不強制統一詮釋→化解共享vs共識）**。
  **騙人處**：一大半是相對主義（真＝社會建構）。當處方＝共識製造機。
- **神學（先知/祭司/君王三職分）**＝**挑戰/維持/決斷**三功能。**獨有貢獻＝權能分立**：病態是「一職俘獲他職」，
  且每種俘獲預測一種病（君俘先＝暴政/共識引力；祭俘先＝僵死正統/制度俘獲；一人三職＝知識絕對主義）。
  「三職只在『本身即真』的那位合一，墮落者必須分立」＝**只有完美 oracle 能一手包，沒有→必須分權**。
  **騙人處**：宗教權威＝啟示/信心＝**不可證偽**＝膜的反面；正統/異端重力拉向單一栽培。→ **先知必須可證偽**。

## 跨域驗證 ＋ 我去獵殺它（最有價值的一段）
**先對「動作本身」套膜**：堆確認＝retrofit/共識引力。所以 (1) 找**給定理**的領域 ground，(2) **主動找 break**。
- **ML（使用者的場，把原則變定理）**：**集成只有在誤差『去相關』時才有用**→「**保護異議/多樣性＝聚合能成立的
  數學前提**」（共識引力＝相關誤差＝集成失效）。對抗訓練＝先知當訓練訊號；**model collapse＝複利而不污染的定理版**；
  正則化＝過度擬合檢查本尊。
- **分散式/BFT（獨立、amend 我們）**：互不信任節點能穩健一致——**但只對「記錄/次序」不對「真」**，且壞<1/3。
  → **修正：把「對記錄/provenance 的共識」（可分散、穩健）和「對真的判斷」（不可投票）分開**。CAP＝一致/可用/分區
  不可兼得＝共享庫必犧牲一個。
- **市場（Hayek）**：分散知識無中央 oracle（confirm 分權）；泡沫＝相關誤差共識（confirm）；需制度（＝oracle）。
- **獵到的 BREAK（scope 邊界）**：**時間壓力下的行動系統（手術/駕駛艙/戰場）刻意集中權力、壓制異議，而且對。**
  → **原則的 scope：適用「知識形成」（慢、求真），不適用「行動執行」（快、求協調）——那裡它反轉。**
  （這也解釋場層為何慢衰減+人閘門＝它是知識形成不是行動執行。）
- **誠實折扣**：生物/社會/神學的「確認」我很可能挑了符合的、忽略不符的，證據力打折。**真正有力的只有：
  給了定理的（ML去相關、BFT/CAP）＋我獵殺卻只找到 scope 邊界沒找到致命矛盾的（行動執行）。**
  一個怎麼砸都砸不破的原則要懷疑在 retrofit；**有乾淨 break＋兩條定理，比 survives-everything 更可信。**

## 候選根因（⚠️ 只提議、等人冊封；且只有 commit 聯邦方向才有意義）
> **在「知識形成」場景（非行動執行）：保護『去相關的異議』（那是聚合能成立的數學前提）、把『記錄的共識』
> 與『對真的判斷』分開、死守一條所有類比都沒有的 grounding oracle；三功能（挑戰/維持/決斷）分立互檢。**
- 帶了**scope 邊界**（行動執行反轉）＋**定理地基**（去相關＝集成前提）——比「撐過四個比喻」硬。
- 四透鏡收斂的橋接根因＝**「保護異議」**（Treg=認知分工=場層慢衰減=先知）——撐過四方盤問。

## 被否決的框架（committed 才 tombstone 進 history）
- ❌「匯集各 base → 變共享知識」（匯集優先）＝典型過度抽象＋**共享的膜缺席＝共享的污染**。
- ❌ 照抄免疫（自己/非己 ≠ 真/假）／照抄社會學（相對主義＝共識機）／照抄神學（啟示＝不可證偽）——**偷機制、丟形上學**。

## 開放問題（下一個真問題）
- 把「**反共識引力**」縫成具體機制：異議**免費＋被主動分配注意力預算**＋共享根因用**邊界物件不強制統一詮釋**＋
  **雙訊號**升 bedrock。
- 怎麼**實際計算**「A 的主張撐不撐得過 B 的膜」（拿 B 的根因+oracle 交叉盤問）＝這道膜的心臟、也最難。
- 便宜驗法：先拿自己 2–3 個 base 掛上膜，做「出處向量＋攤開矛盾」，看有沒有真感，再談治理。

## 可建的第一步：C-MVP＝跨場候選過自家閘門（2026-08-06 使用者定調）
使用者重申模型：**先各自隔離，再由膜治理「知識怎麼跨場流動」——不是大家共編一個庫**（＝上面 line 18–24 的聯邦、非匯集）。
新增一個**能真的動手、又完全守主權**的最小原語，把「這道膜的心臟」（line 77 開放問題）的**產品版起點**落地：

> **發布一條根因（帶出處）＋ 別人把它當「候選」、過自己的試金石＋自己冊封才收下。**

- **它就是既有的單人閘門、只換來源**：單人版＝沙盒→膜→地基、AI 提議/人冊封（原則 6）。C-MVP＝**同一道閘門，但「候選」
  現在可來自別人發布的場**，收下＝過**你的**試金石＋**你的**冊封。→ 聯邦是**把原則 6 的閘門放大、不是另起爐灶**（架構連續，
  **spec 032「候選→冊封」流即其種子**——只要多開一個「候選來源＝別人發布的根因（附 provenance）」）。
- **不投票、不合併、不共編**：符合 line 23「撐過各自把關非投票」、line 22「反權威洗白」。
- ****同一個馬太陷阱****：「多少場採用了這條」**絕不餵回排序**——跟單人版 [收進的活化沉降與核心理解拓撲](2026-08-05-收進的活化沉降與核心理解拓撲.md) #3 的
  「引用頻率別餵檢索排序」是**同一條**，跨場版更危險（共識引力，line 29）。
- 它**不解** line 77 的難心臟（自動判「撐過多場」），但給了**不必等它就能起步**的第一增量：手動發布＋手動過閘門收下、出處保留。

## 上線分階：把聯邦接到部署（2026-08-06）
動機（使用者）：上線但**別被看光** ＋ **服務其他類似需求的人** ＋ **共享知識一起進步**。拆三件（工程量與靈魂親疏差很大）：
- **A 登入牆**（就你能進）＝最小、安全上線；單人 auth、**不需**多租戶。
- **B 多租戶**＝每人一個**隔離**的場（user_id）＝本 draft line 15「先聯邦自己的 base」。
- **C 聯邦膜**＝上面的 C-MVP → C-full（自動跨場驗證＋三職治理，北極星）。
順序：**A→B→C-MVP→C-full**。UI 全程 server-rendered＋htmx 即可（見 [部署與介面路線](../history/013-Web-介面完成.md)）。

# 2026-08-26 的五輪：形狀、信任鏈、隱私、Access Control、雲端硬碟的像

> ⓘ 這一大段（約 250 行）是同一天五輪 chat-only 討論的沉澱。
> **全部未升進路線圖**——這條線在等的東西一直沒變：**第二個使用者**。
> 它現在的規模已經該獨立成一份 draft 了；等真的要動工再拆，現在拆只是搬字。

> ⓘ 以下是同一天四輪 chat-only 討論的沉澱，**都未升進路線圖**。
> 讀法：**形狀**（什麼東西跨過邊界）→ **信任鏈**（跨過之後怎麼判斷它）
> → **隱私**（鏈可以走到哪裡）→ **AC**（誰看得到什麼）→ **雲端硬碟的像**（借哪一半）。
> 五段是同一條線的五層。

## 一、形狀：從「共享理解」改成「發布應用」

使用者提出一個**比 C-MVP 更保守、而且更便宜**的形狀：

> **不共享理解，而是把成果做成「應用」發出去，變成別人的「來源」**——message passing。
> 大家有一個共享空間收集發過來的知識，可以廣播到 room 或直接發給對象。

### 為什麼它不需要新的認識論

膜的三層份量已經寫死在 prompt 裡（`field_chat.py`）：
**理解＝地基 · 收藏的文章/論文＝外部證言 · web＝最外圈**。

別人的東西以**來源**進來 ⇒ 它自動落在「外部證言」那一層，而那**正是它應得的份量**。
⇒ C-MVP 要新增「候選來自別人的場」＋跨場 provenance；這個**一行新機制都不用**。

＋ 它順手解掉一個 C-MVP 有而這個沒有的問題：**社交壓力**。
C-MVP 下提議者是**人**（他冊封過它、他相信它），拒絕有社交代價；
一份來源**不會要求你冊封它**——你讀了，改變了理解，你冊封的是**你自己的話**。

⇒ 一般化：**改變「什麼東西跨過邊界」，邊界就不需要新規則。** 比在邊界上加規則便宜得多。

### 流向因此閉環

`來源 → 對話 → 理解 → 應用 →（別人的）來源 → …`
**一個人的出海口是另一個人的進水口。**
ⓘ 這回收了 spec 053 把「文章」改名「應用」的理由（用途 > 形式）。

### ⚠️ 但有一個前提被打破了

`field_chat.py` 逐字寫著 spec 042 為何關掉 model collapse 閘門：
「那道閘門擋的是 model collapse，**前提是文章為 AI 產物；來源不是**」。

**別人發過來的應用是 AI 產物。** 它以來源身分進來時，那道閘門是關著的
——而它本來就是為這種東西開的。而且會複合：
A 的應用 → B 的來源 → B 的理解 → B 的應用 → C 的來源⋯**每一跳都是 AI 產物被當成一手材料**。

⇒ 必須新增的唯一東西：**來源要記得「它是不是別人的產出」**。
一個欄位，但漏掉沒有任何跡象——模型照樣流暢作答。

## 二、權威＝可走到底的信任鏈 ＋ 你自己選擇信任哪一道閘門

使用者的定義（2026-08-26）：

> 「最終可以追溯到某一篇論文的**數據**，然後我也信任這論文的作者以及**審查機制**
> ——而不是我看是權威人士寫的就全盤接受」

⇒ 兩個結構性質，兩個都可建：

**① 信任鏈只有在觸底時才值錢。** 論文是好終點不因為作者有名，
而因為它**停在非推導的東西上**（數據、實驗、可重現步驟）。
**現況看不出來有沒有觸底**：`evidence_urls` 是扁平 URL 陣列（`TEXT DEFAULT '[]'`），
**沒有型別**——「部落格引部落格引部落格」從任何單一節點看都是健康的。

**② 信任放在機制上，不是節點上。** 同儕審查是一道閘門；冊封也是。
⇒ 鏈不告訴你要不要信，它告訴你**什麼被檢查過、經過哪一道閘門**，你自己決定信哪種。
而閘門分種類：preprint ≠ 同儕審查 ≠ 被複現 ≠ 你自己冊封過。
**這就是它不會變成權威洗白的原因**（本檔 line 22 那條紀律因此仍然成立）。

### 兩件因此可建、而且只有機器做得到

- **鏈的觸底檢查**：「3 跳 → arXiv:1706.03762 的實驗數據 ✅」
  vs「5 跳之後**繞回你自己的一篇應用** ⚠️」。
  ⚠️ 循環引用與無底鏈**從任何單一節點看都正常**，只有走完整條才看得出來
  ⇒ 正是分工判準：AI 做機械的（走鏈）、人做語意的（決定信不信那道閘門）。
- **層次 vs 鏈的對帳**：`why_nodes.kind`（已證實／推論／類比／猜想）是**你的宣稱**，
  鏈是那個宣稱的**憑據**——它們可以打架。
  一條標「已證實」但引用鏈**沒有觸底**的理解，是一個**可檢查的矛盾**。
  **大多數知識問題沒有 oracle**，而**這個有**；不查就永遠不現形（徽章照樣掛著）。

### 引用鏈在一個場內**已經整條落庫了**

```
理解 ──conversation_id──> 對話 ──carried_ref──> 來源
  └──source_entry_id──> 來源塊     └──src_from/to──> 哪幾則
應用 ──article_roots──> 理解（分本文／延伸層）
```

⇒ **聯邦只需要多一種邊**：`來源 ← 別人的應用`。整條鏈就跨人接起來了。
＋ 走鏈的遞迴 CTE **已經真跑驗過雙後端**（含環也終止，`UNION` 去重；PG 需 `CAST`）。
⇒ 真正的新工作只有：`evidence_urls` 加型別、跨人那條邊。

## 三、隱私把信任鏈補完了：第三種終點

使用者：「有些**如果對方沒有公開給你看**，那你就只能憑對方的理解成為來源了；
而如果**對話有公開**，你甚至可以看到對方是如何發展出這理解的。」

### 鏈有三種終點，認識論地位完全不同

| 終點 | 你能做什麼 |
|---|---|
| **觸底** | 走到數據／實驗 → **可檢查**（證據） |
| **無底／循環** | 走不到地 → **沒有憑據**（病態） |
| **遮蔽** | 憑據**存在**但你**看不到** → 只能採信（**證詞**） |

⚠️ **遮蔽的終點 MUST NOT 長得像觸底的終點。** 顯示成「3 跳 → 某人的理解 ✅」
就是**把證詞洗成證據**。必須是：`3 跳可見 → ⛔ 到此為止：對方沒有對你公開`。

### 遮蔽壓縮的是**解析度**，不只是內容

看不見的那一段，20 跳或 1 跳對你都塌縮成**一跳「他說的」**
⇒ 你無法分辨「他也是隨口說的」與「他背後有五篇論文」。

⇒ 這就是「公開對話」的價值：**它把解析度還給你**——你看得到他**有沒有依據**。
ⓘ 接上 `experience.md` 那條：「風險住在**有沒有依據**那一軸，不是**誰講的**」
（使用者原話：「如果只有我自己講的話，常常是沒有依據的」）。
只公開理解，會讓那一軸**消失**。

### 揭露梯度跟流向是**反的**，而教學價值又跟梯度相反

```
來源 → 對話 → 理解 → 應用
最暴露 ←──────────────→ 最安全
最有教學價值 ←────────→ 最沒有
```

越下游越適合公開（應用是打磨過的成品）；越上游越暴露
（對話有半成形的想法與死路；**來源清單**直接說出你在關心什麼、還不懂什麼）。

而老師真正需要看的正是**對話**——誤解就住在那裡，成品裡看不到。
**這不是預設值解得掉的**，它是關係的性質。工具能做的是**讓它明講，不是默默發生**。

⇒ 好消息：**膜的四層本身就是天然的預設**，room 只是換一組預設。不必另設權限矩陣。

## 四、Access Control 的形狀（純揭露範圍，**無可信度含意**）

> 「例如課堂上老師可以完整看到學生的，但是學生可能需要公開才能夠讓另外一個學生看到」

- **不是階梯，是有向關係。** 老師看得到學生、學生看不到彼此
  ⇒ 結構上是**有向圖**，「階級」在課堂裡的意思是**關係裡的角色**。
  一個 `level: int` 表達不了「老師看得到我的對話、同學看不到、但這一條我特別公開給同學」。
- **兩個獨立維度，MUST NOT 塌成一個數字**：
  **角色給的**（room 決定：老師看得到學生） vs **自選的**（本人決定：公開某一條給同學）。
  ⇒ 最小原語：**`(層, room) 的預設` ＋ `每件知識的覆寫`**。
- ⓘ 層級管**可見性**，不管**權重**——一條理解的份量不因它來自哪一層而變，
  變的只是你看得到多少（同本檔 line 22「反權威洗白」）。

### 可見性 MUST 在**產生內容的當下**看得見

room 給了老師看對話的權限的話，學生要在**打字的時候**就看得到
——寫在設定頁裡等於監看。

ⓘ 這個位置已經存在：spec 054 定過「**麵包屑是『我現在會影響誰』的唯一指示**」，
且刻意擺在「＋新對話」**上面**（「你按下它之前，要先看得到它會生在哪」）。
⇒ 多人版只是同一個槽位多一個軸：**「我現在講的話，誰看得到」**。

### ⚠️ 撤銷 vs 已經走過的鏈

A 公開 → B 走了鏈、形成理解 → **A 取消公開**。
若鏈只記「**現在**看不看得到」，A 的一個動作就**回頭改寫了 B 當初的推理依據**
——B 的理解看起來變得比當時沒有根據，而**B 不會收到任何通知**。

⇒ 鏈要記的是「**你形成這個理解時看得到什麼**」，不是「現在看得到什麼」。
ⓘ 同封存的判準：**位址留著、內容可以走**。B 的鏈上該顯示
「這一段當時可見，`YYYY-MM-DD` 之後不再公開」——誠實，且不篡改 B 的過去。

### 一個結構統一：鏈是 `(鏈, 觀察者)` 的屬性

公開程度因人而異 ⇒ 同一條理解對不同人有**不同的可見深度**。
**那跟 spec 052 的 `(邊, 立足點)` 是同一個結構**——這個庫已經因為糾纏踩過一次
「把關係當成屬性快取起來會全錯，而且不報錯」。

⇒ 兩個後果：**「這條鏈」不能快取，只有「X 眼中的這條鏈」能**；
而**全域的可信度分數在結構上不成立**——這反而**加強**了不准計分的規則。

## 五、「像雲端硬碟」——借它的櫃子，不要借它的「共用」

使用者：「這樣的共享知識搭配使用者機制就會像是**雲端硬碟**般的存在」。

拿本庫自己的判準去對（`experience.md`：**比喻借的是「形狀」，不是「代價」**）：
**容器那一半對得很好，內容那一半整個相反。**

### 對得上的（都已經蓋好了）

| 雲端硬碟 | 這裡 |
|---|---|
| 資料夾／檔案／捷徑 | 領域／知識／糾纏（spec 048–050） |
| 兩欄檔案總管、麵包屑、右鍵 | spec 057 |
| 逐項分享給特定人 | 上面第四節的 AC |
| 「與我共用」 | 收件匣 |

⇒ 這一半是真價值：**使用者不必學怎麼導覽，他已經會了。**

### 對不上的四件，第一件是根本的

1. **雲端硬碟共享的是「同一個物件」，這裡共享的是「一則訊息」。**
   Google Docs 是一份文件 N 個人看；這裡沒有共同擁有的東西
   ——你收到的是**拷貝**，而且它**落在不同的層**。
2. **雲端硬碟裡的檔案是惰性的，這裡的知識會動。**
   Dropbox 多一個 PDF 不會改變你其他檔案的意思；收進一份來源**會改變你的助手怎麼回答**。
   ⇒ 這就是為什麼這裡需要閘門而雲端硬碟不需要：**收下一個檔案不會對你做任何事，收下一則知識會。**
3. **雲端硬碟沒有「份量」這個維度。** PDF 就是 PDF；而這裡同一段內容在不同層份量不同
   （理解＝地基／來源＝外部證言／應用＝自家衍生物）
   ——**這個系統裡最重要的屬性，在硬碟裡沒有對應物。**
4. **刪除的代價不同**（已處理）：硬碟有回收桶，這裡是封存／抹除兩段式。

### 因此有一個真實的風險：**像什麼，就會被期待成什麼**

| 使用者會帶來的預期 | 實際 |
|---|---|
| 「我分享了，所以我們在看同一份」 | 他看的是**拷貝** |
| 「我取消分享，他那邊就沒了」 | 鏈記住了「他當時看得到」（見第四節） |
| 「我改了他會看到」 | 沒有同步 |

**這些誤解不會報錯**——它們會表現成「這個工具怪怪的」。

⇒ 判準：**介面在語意不同的地方，必須主動打破那個像。** 三個具體做法：

1. 那個動作叫**「發送」**不叫「共用」——你送出的是拷貝。
2. 收到的東西進**收件匣**，動作是「**收進你的場**」，不是「已加入你的雲端硬碟」。
3. **在收下的當下顯示層的變化**（最值得做的一個）：

   > 這是他的 💡**理解** → 收進你這裡會變成 📚**來源**
   > （比理解軟：可引用，但別當成你的地基）

   ⇒ 它把最容易誤解的那件事，放在**最不可能錯過的時刻**，而且用的是**膜本來就有的詞**。

## 接著要想清楚的三件（尚未決定）

1. **誰的 `domain_id`？** 用他的路徑 → 你的樹被別人的分類法污染；用你站的地方 → 對。
   ⇒ 沿用 spec 051：**出處在別人的場＝沒有訊號**（同「出處在根領域」），退回你站的地方。
   **現有規則直接就能用。**
2. **糾纏多了第三個軸。** spec 052 定的是 `(邊, 立足點)`；多人之後是 `(邊, 立足點, 誰的場)`。
   側欄那句「通往外面 N 條」要分得出**「通往我的別的領域」**與**「通往別人的場」**。
3. **共識是社會版的沉默失敗。** 原則 5 要 AI 對自己 adversarial 以防 folie à deux；
   多人版更強：**兩個人互相冊封對方的理解，會產生一個沒有任何 adversarial 來源的閉環**，
   而它不會報錯——雙方都覺得越來越清楚。
   ⇒ 判準：**問「這條理解如果錯了，這個群體裡誰會發現？」**
   答案是「沒有人，因為我們都是從對方那裡拿的」⇒ 不該算已證實，不管幾個場採用過。
   ⓘ 這是 [沉默的失敗不會自己現形](../concepts/沉默的失敗不會自己現形.md) 的社會版：
   **共識特別難察覺，因為每個參與者都得到了正向回饋。**

## 兩個設計判斷

- **共享空間必須是收件匣，不是資料庫。** 共同儲存會違反「先各自隔離」
  ⇒ 它是**佇列**：東西停在那裡直到你**收進**自己的場。沒有共享狀態，只有傳輸中的訊息。
- **廣播 vs 直送，差別在「誰決定它相關」。** 直送＝發的人承擔相關性判斷；
  廣播＝**沒有人決定**，那就是洪流——正是北極星第一條（用信任過濾，不用廣度）的反面。
  ⇒ 廣播要配一個進水口閘門，否則 room 會變成另一個 Slack。直送天然就有閘門：**你選擇跟誰交換**。
