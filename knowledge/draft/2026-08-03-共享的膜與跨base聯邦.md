# 共享的膜 ＋ 跨 base 聯邦（knowie 前端的未來方向）

> 狀態：**draft／未定案設計（thinking-line）**。日期：2026-08-03。全是**發想**——外推一道**還沒蓋、還沒驗**
> 的膜，先當假說。成熟出口＝**vision 路線圖（要人 commit 才升）**；在那之前不進三大檔。

## 起點：工具收斂成 knowie，chat+websearch 是原子單位
1. 使用者想砍掉一堆進料/新聞分診的舊功能（轉向前的殘骸）。砍完剩下的核心＝`跟知識聊`→`根因`→`對話存檔`，
   **骨架本來就是 knowie 形狀**（根因=principles、暫存/永久=draft/episodes）。
2. 關鍵洞見：**「chat-only 發想 ＋ 要 AI 查 web」就是使用者工作的原子單位**（他連跟我 chat-only 都在做這件事）；
   其餘功能都是繞著它的鷹架。KnowField 的 `/chat` ＝這件事的**有紀律版**（有膜、有捕捉、有場 grounding），
   Claude Code 裡的 chat-only ＝**原始版**（無膜、會蒸發、不 grounded）。
3. 願景（未定案）：一個**聯邦多個 knowie base ＋個人場**的前端，讓資訊成為**共享知識**。
   - **膜頂回**：不是「讓 KnowField 長得像 knowie」，而是「把使用者本來就在做的那件事，給它一個**同時有紀律
     （膜）又可攜（knowie markdown）**的家」。
   - **分階**：先聯邦**自己的** base（單一把關、純度可控）；**跨人共享**是研究等級難題、先當北極星別當 sprint。

## 設計：共享的膜（跨 base）
生成根：**單一 base 的膜讓「你對自己」誠實；共享的膜讓「base 對 base」誠實——但絕不塌縮成共識。**
工作＝**讓分歧可讀、讓出處透明，不是製造同意。**
- **出處向量**：每條主張帶「在 A 的經驗層 grounded、在 B 沉默、跟 C 矛盾」，不再只是 grounded/猜。
- **矛盾是訊號、絕不平均**：跨 base 矛盾要**主動獵取、攤開、分類**（尺度不同／開放問題／有一個錯），不揉成共識。
- **反權威洗白**：A 的 bedrock 到 B 只能當**提案/猜**，得經 B 的膜獨立 ground（反逢迎的群體版）。
- **共享根因＝撐過每個 base 各自的把關**（像定理在多套公理系統各自可證），**不是投票**；門檻更高、非妥協平均。
- **權能分立（來自神學三職分，見下）**：挑戰／維持／決斷三功能**分立且互檢**，別讓一個 base/人一手包。

## 規模化的湧現（好壞是同一台機器）
- **好**：跨場橋接根因（撐過多 oracle 的不變量）、矛盾地形（＝前沿地圖）、共享免疫（幻想沒法不被獨立驗過就傳開）。
- **壞**：共識引力（多數即真理、壓死可能對的異議）、接地通膨（grounded-once-沒人重驗＝引用洗白）、
  出處崩塌（鏈長到沒人追＝溯源劇場）、單一栽培（追共享根因餓死在地 novelty）。
- **皇冠**：給你橋接根因/免疫的那條「撐過每個膜」規則，同一條在規模下就長成共識引力/單一栽培。
  **免疫系統＝自體免疫的風險，同一台機器。→ 真正的設計問題：怎麼讓免疫不殺死還沒兌現的 novelty（＝保護異議）。**

## 四透鏡交叉盤問（brainstorming scene：why 的 why）
用「撐過多個獨立 oracle」的方法驗設計原則自己。每個透鏡：**貢獻一個機制 ＋ 標出它在哪裡騙人。**
- **生物（免疫/細胞膜）**：主動運輸（純度燒能量、停了＝熵＝那些失敗）／先天+後天雙臂（快通用膜＋慢特異冊封）／
  免疫記憶（**傳抗體=為何X錯，不只傳根因**）／**雙訊號 costimulation（升 bedrock 要「同意＋grounding 理由」兩訊號，
  單訊號→容忍不 commit ＝擋共識引力）**／**Treg（專職保護 novelty）**／自體免疫-過敏-免疫缺陷＝診斷詞彙。
  **騙人處**：免疫優化「自己/非己」，知識要優化「真/假」——正交。照抄＝排外＋自我崇拜（拒外來真、護native幻想）。
- **社會學**：偏好造假（**把異議變便宜**）／馬太效應（grounding 逐條重賺、不繼承聲望）／泡泡vs迴音室（兩種病兩種藥）／
  制度俘獲（閘門＝機制非權威）／組織化懷疑（**制度化的挑戰、指派 skeptic**）／證言（**信任但標記**、不可能每條都驗）／
  **認知分工（結構性資助少數派＝Treg 的社會版）**／**邊界物件（共享物件、不強制統一詮釋→化解共享vs共識）**。
  **騙人處**：一大半是相對主義（真＝社會建構）。當處方＝共識製造機。
- **神學（先知/祭司/君王三職分）**＝**挑戰/維持/決斷**三功能。**獨有貢獻＝權能分立**：病態是「一職俘獲他職」，
  且每種俘獲預測一種病（君俘先＝暴政/共識引力；祭俘先＝僵死正統/制度俘獲；一人三職＝知識絕對主義）。
  「三職只在『本身即真』的那位合一，墮落者必須分立」＝**只有完美 oracle 能一手包，沒有→必須分權**。
  **騙人處**：宗教權威＝啟示/信心＝**不可證偽**＝膜的反面；正統/異端重力拉向單一栽培。→ **先知必須可證偽**。

## 跨域驗證 ＋ 我去獵殺它（最有價值的一段）
**先對「動作本身」套膜**：堆確認＝retrofit/共識引力。所以 (1) 找**給定理**的領域 ground，(2) **主動找 break**。
- **ML（使用者的場，把原則變定理）**：**集成只有在誤差『去相關』時才有用**→「**保護異議/多樣性＝聚合能成立的
  數學前提**」（共識引力＝相關誤差＝集成失效）。對抗訓練＝先知當訓練訊號；**model collapse＝複利而不污染的定理版**；
  正則化＝過度擬合檢查本尊。
- **分散式/BFT（獨立、amend 我們）**：互不信任節點能穩健一致——**但只對「記錄/次序」不對「真」**，且壞<1/3。
  → **修正：把「對記錄/provenance 的共識」（可分散、穩健）和「對真的判斷」（不可投票）分開**。CAP＝一致/可用/分區
  不可兼得＝共享庫必犧牲一個。
- **市場（Hayek）**：分散知識無中央 oracle（confirm 分權）；泡沫＝相關誤差共識（confirm）；需制度（＝oracle）。
- **獵到的 BREAK（scope 邊界）**：**時間壓力下的行動系統（手術/駕駛艙/戰場）刻意集中權力、壓制異議，而且對。**
  → **原則的 scope：適用「知識形成」（慢、求真），不適用「行動執行」（快、求協調）——那裡它反轉。**
  （這也解釋場層為何慢衰減+人閘門＝它是知識形成不是行動執行。）
- **誠實折扣**：生物/社會/神學的「確認」我很可能挑了符合的、忽略不符的，證據力打折。**真正有力的只有：
  給了定理的（ML去相關、BFT/CAP）＋我獵殺卻只找到 scope 邊界沒找到致命矛盾的（行動執行）。**
  一個怎麼砸都砸不破的原則要懷疑在 retrofit；**有乾淨 break＋兩條定理，比 survives-everything 更可信。**

## 候選根因（⚠️ 只提議、等人冊封；且只有 commit 聯邦方向才有意義）
> **在「知識形成」場景（非行動執行）：保護『去相關的異議』（那是聚合能成立的數學前提）、把『記錄的共識』
> 與『對真的判斷』分開、死守一條所有類比都沒有的 grounding oracle；三功能（挑戰/維持/決斷）分立互檢。**
- 帶了**scope 邊界**（行動執行反轉）＋**定理地基**（去相關＝集成前提）——比「撐過四個比喻」硬。
- 四透鏡收斂的橋接根因＝**「保護異議」**（Treg=認知分工=場層慢衰減=先知）——撐過四方盤問。

## 被否決的框架（committed 才 tombstone 進 history）
- ❌「匯集各 base → 變共享知識」（匯集優先）＝典型過度抽象＋**共享的膜缺席＝共享的污染**。
- ❌ 照抄免疫（自己/非己 ≠ 真/假）／照抄社會學（相對主義＝共識機）／照抄神學（啟示＝不可證偽）——**偷機制、丟形上學**。

## 開放問題（下一個真問題）
- 把「**反共識引力**」縫成具體機制：異議**免費＋被主動分配注意力預算**＋共享根因用**邊界物件不強制統一詮釋**＋
  **雙訊號**升 bedrock。
- 怎麼**實際計算**「A 的主張撐不撐得過 B 的膜」（拿 B 的根因+oracle 交叉盤問）＝這道膜的心臟、也最難。
- 便宜驗法：先拿自己 2–3 個 base 掛上膜，做「出處向量＋攤開矛盾」，看有沒有真感，再談治理。
