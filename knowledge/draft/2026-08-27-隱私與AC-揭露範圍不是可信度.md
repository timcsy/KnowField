## 三、隱私把信任鏈補完了：第三種終點

使用者：「有些**如果對方沒有公開給你看**，那你就只能憑對方的理解成為來源了；
而如果**對話有公開**，你甚至可以看到對方是如何發展出這理解的。」

### 鏈有三種終點，認識論地位完全不同

| 終點 | 你能做什麼 |
|---|---|
| **觸底** | 走到數據／實驗 → **可檢查**（證據） |
| **無底／循環** | 走不到地 → **沒有憑據**（病態） |
| **遮蔽** | 憑據**存在**但你**看不到** → 只能採信（**證詞**） |

⚠️ **遮蔽的終點 MUST NOT 長得像觸底的終點。** 顯示成「3 跳 → 某人的理解 ✅」
就是**把證詞洗成證據**。必須是：`3 跳可見 → ⛔ 到此為止：對方沒有對你公開`。

### 遮蔽壓縮的是**解析度**，不只是內容

看不見的那一段，20 跳或 1 跳對你都塌縮成**一跳「他說的」**
⇒ 你無法分辨「他也是隨口說的」與「他背後有五篇論文」。

⇒ 這就是「公開對話」的價值：**它把解析度還給你**——你看得到他**有沒有依據**。
ⓘ 接上 `experience.md` 那條：「風險住在**有沒有依據**那一軸，不是**誰講的**」
（使用者原話：「如果只有我自己講的話，常常是沒有依據的」）。
只公開理解，會讓那一軸**消失**。

### 揭露梯度跟流向是**反的**，而教學價值又跟梯度相反

```
來源 → 對話 → 理解 → 應用
最暴露 ←──────────────→ 最安全
最有教學價值 ←────────→ 最沒有
```

越下游越適合公開（應用是打磨過的成品）；越上游越暴露
（對話有半成形的想法與死路；**來源清單**直接說出你在關心什麼、還不懂什麼）。

而老師真正需要看的正是**對話**——誤解就住在那裡，成品裡看不到。
**這不是預設值解得掉的**，它是關係的性質。工具能做的是**讓它明講，不是默默發生**。

⇒ 好消息：**膜的四層本身就是天然的預設**，room 只是換一組預設。不必另設權限矩陣。

## 四、Access Control 的形狀（純揭露範圍，**無可信度含意**）

> 「例如課堂上老師可以完整看到學生的，但是學生可能需要公開才能夠讓另外一個學生看到」

- **不是階梯，是有向關係。** 老師看得到學生、學生看不到彼此
  ⇒ 結構上是**有向圖**，「階級」在課堂裡的意思是**關係裡的角色**。
  一個 `level: int` 表達不了「老師看得到我的對話、同學看不到、但這一條我特別公開給同學」。
- **兩個獨立維度，MUST NOT 塌成一個數字**：
  **角色給的**（room 決定：老師看得到學生） vs **自選的**（本人決定：公開某一條給同學）。
  ⇒ 最小原語：**`(層, room) 的預設` ＋ `每件知識的覆寫`**。
- ⓘ 層級管**可見性**，不管**權重**——一條理解的份量不因它來自哪一層而變，
  變的只是你看得到多少（同本檔 line 22「反權威洗白」）。

### 可見性 MUST 在**產生內容的當下**看得見

room 給了老師看對話的權限的話，學生要在**打字的時候**就看得到
——寫在設定頁裡等於監看。

ⓘ 這個位置已經存在：spec 054 定過「**麵包屑是『我現在會影響誰』的唯一指示**」，
且刻意擺在「＋新對話」**上面**（「你按下它之前，要先看得到它會生在哪」）。
⇒ 多人版只是同一個槽位多一個軸：**「我現在講的話，誰看得到」**。

### ⚠️ 撤銷 vs 已經走過的鏈

A 公開 → B 走了鏈、形成理解 → **A 取消公開**。
若鏈只記「**現在**看不看得到」，A 的一個動作就**回頭改寫了 B 當初的推理依據**
——B 的理解看起來變得比當時沒有根據，而**B 不會收到任何通知**。

⇒ 鏈要記的是「**你形成這個理解時看得到什麼**」，不是「現在看得到什麼」。
ⓘ 同封存的判準：**位址留著、內容可以走**。B 的鏈上該顯示
「這一段當時可見，`YYYY-MM-DD` 之後不再公開」——誠實，且不篡改 B 的過去。

### 一個結構統一：鏈是 `(鏈, 觀察者)` 的屬性

公開程度因人而異 ⇒ 同一條理解對不同人有**不同的可見深度**。
**那跟 spec 052 的 `(邊, 立足點)` 是同一個結構**——這個庫已經因為糾纏踩過一次
「把關係當成屬性快取起來會全錯，而且不報錯」。

⇒ 兩個後果：**「這條鏈」不能快取，只有「X 眼中的這條鏈」能**；
而**全域的可信度分數在結構上不成立**——這反而**加強**了不准計分的規則。

## 五、「像雲端硬碟」——借它的櫃子，不要借它的「共用」

使用者：「這樣的共享知識搭配使用者機制就會像是**雲端硬碟**般的存在」。

拿本庫自己的判準去對（`experience.md`：**比喻借的是「形狀」，不是「代價」**）：
**容器那一半對得很好，內容那一半整個相反。**

### 對得上的（都已經蓋好了）

| 雲端硬碟 | 這裡 |
|---|---|
| 資料夾／檔案／捷徑 | 領域／知識／糾纏（spec 048–050） |
| 兩欄檔案總管、麵包屑、右鍵 | spec 057 |
| 逐項分享給特定人 | 上面第四節的 AC |
| 「與我共用」 | 收件匣 |

⇒ 這一半是真價值：**使用者不必學怎麼導覽，他已經會了。**

### 對不上的四件，第一件是根本的

1. **雲端硬碟共享的是「同一個物件」，這裡共享的是「一則訊息」。**
   Google Docs 是一份文件 N 個人看；這裡沒有共同擁有的東西
   ——你收到的是**拷貝**，而且它**落在不同的層**。
2. **雲端硬碟裡的檔案是惰性的，這裡的知識會動。**
   Dropbox 多一個 PDF 不會改變你其他檔案的意思；收進一份來源**會改變你的助手怎麼回答**。
   ⇒ 這就是為什麼這裡需要閘門而雲端硬碟不需要：**收下一個檔案不會對你做任何事，收下一則知識會。**
3. **雲端硬碟沒有「份量」這個維度。** PDF 就是 PDF；而這裡同一段內容在不同層份量不同
   （理解＝地基／來源＝外部證言／應用＝自家衍生物）
   ——**這個系統裡最重要的屬性，在硬碟裡沒有對應物。**
4. **刪除的代價不同**（已處理）：硬碟有回收桶，這裡是封存／抹除兩段式。

### 因此有一個真實的風險：**像什麼，就會被期待成什麼**

| 使用者會帶來的預期 | 實際 |
|---|---|
| 「我分享了，所以我們在看同一份」 | 他看的是**拷貝** |
| 「我取消分享，他那邊就沒了」 | 鏈記住了「他當時看得到」（見第四節） |
| 「我改了他會看到」 | 沒有同步 |

**這些誤解不會報錯**——它們會表現成「這個工具怪怪的」。

⇒ 判準：**介面在語意不同的地方，必須主動打破那個像。** 三個具體做法：

1. 那個動作叫**「發送」**不叫「共用」——你送出的是拷貝。
2. 收到的東西進**收件匣**，動作是「**收進你的場**」，不是「已加入你的雲端硬碟」。
3. **在收下的當下顯示層的變化**（最值得做的一個）：

   > 這是他的 💡**理解** → 收進你這裡會變成 📚**來源**
   > （比理解軟：可引用，但別當成你的地基）

   ⇒ 它把最容易誤解的那件事，放在**最不可能錯過的時刻**，而且用的是**膜本來就有的詞**。
