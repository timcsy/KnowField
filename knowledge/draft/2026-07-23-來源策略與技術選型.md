# 來源策略與技術選型（2026 上半年研究快照）

> 怎麼冒出來的：2026-07-23 web 研究。性質：技術/來源設計輸入，餵給階段 1 規格的
> 「來源盤點」與階段 2 的去重管線。captured ≠ committed；查證為單輪 WebSearch，中等可信。

## 來源優先序（建議）
1. **免費論文骨幹**：Semantic Scholar、OpenReview、arXiv、Hugging Face Daily Papers。
2. **RSS**（有就用）。
3. **email-ingestion 兜底**（無 RSS 的電子報）。
4. **付費新聞聚合**（最後手段）。
5. **X 明確降級**（不當核心來源）。

## 各來源現況（含限制）
- **X/Twitter — 最痛且更糟**：2026-02 改按用量計費（發文 $0.015、含連結 $0.20、
  讀取 $0.005，上限 200 萬/月），四個月改兩次；已無實質免費層，Enterprise ~$42k/月。
  → 靠策展 list 或二手聚合，別即時抓。
  - https://www.blotato.com/blog/twitter-api-pricing
  - https://postproxy.dev/blog/x-api-pricing-2026/
- **email-ingestion（成熟解，建議當兜底層）**：Kill the Newsletter（免費/開源/可自架，
  給信箱＋Atom feed）、Meco（連 Gmail，$3.99/月）、Feedbin（$5/月）。2026 RSS 使用量 YoY +34%。
  - https://www.readless.app/blog/email-to-rss-2026
- **Semantic Scholar**：仍免費但收緊——最高速率方案棄用、官方推自架資料集、要求指數退避。
  當骨幹可，勿假設高吞吐。
  - https://github.com/allenai/s2-folks/blob/main/API_RELEASE_NOTES.md
  - **⚠ 實測（2026-07-23 MVP 真跑）**：free search 端點**持續回 429**（連退避後仍失敗），
    實務上幾乎供不了料。HF Daily Papers 反而穩定。→ 建議把 S2 降級或換穩定來源
    （階段 3 來源盤點再處理）。
- **arXiv / OpenReview**：未查到 2025-2026 重大變更（=大致穩定，未證實，規格前自行確認）。
- **HF Daily Papers**：可訂閱每日 email（工作日），本身即現成來源。
  - https://github.com/huggingface/blog/blob/main/daily-papers.md
- **一般新聞聚合 API**：免費層多禁商用、100–200 req/天；付費 NewsAPI.org $449/月起、
  NewsCatcher $50/月起（6000 credits≈600 篇）。GDELT 仍免費海量（2026 條款未證實）。
  - https://thunderbit.com/blog/best-news-apis-compared
- **Scraping 法律邊界**：Meta v. Bright Data（2025 初和解）——抓未登入公開頁不違反
  CFAA，但**登入接受 ToS 後合約請求成立**。→ 優先公開頁、尊重 robots/ToS、避免登入抓。
  這與「可信任、可溯源」定位一致。
  - https://www.fbm.com/publications/major-decision-affects-law-of-scraping-and-online-data-collection-meta-platforms-v-bright-data/

## 技術 SOTA（三塊）
1. **去重／事件叢集**：主流轉向 dense/LLM embedding + 叢集；近似去重用 cosine 門檻下
   連通分量分群；語義叢集 SOTA 為**多語 Matryoshka embeddings**（分主題/事件/敘事粒度）、
   **entity-aware 上下文嵌入**。→ 「同一則」常是同組實體/事件的改寫，**去重用 entity-aware**。
   - https://arxiv.org/pdf/2506.00277 ; https://arxiv.org/abs/2406.10552
2. **溯源式生成（=護城河）**：商用模型引用幻覺率 **11–57%**；「正確 ≠ 忠實」（模型會
   事後合理化引用）。SOTA 朝句級/子句級細粒度歸因＋檢索驗證。**我們不生成結論＝繞開
   這個坑**，強化原則 3/4，是定位優勢不只技術選擇。
   - https://arxiv.org/html/2510.17853v4 ; https://dl.acm.org/doi/pdf/10.1145/3731120.3744592
3. **個人化排序**：興趣 embedding + learning-to-rank，明講清單當冷啟動 prior、
   點擊/拉取當線上更新——即 Scholar Inbox 做法，對齊 [[興趣畫像]]。
