# 來源直接對話：從「它猜哪些相關」到「我說就是這一份」

> 狀態：**已兌現**（vision 階段 38，出貨 2026-08-21，spec `specs/042-source-in-chat/`，commit `3aa6b46`）。
> 本檔留為設計理由；轉移見 [history/103](../history/103-來源直接對話-撒網的失敗是沉默的.md)。
> 怎麼冒出來的：使用者在階段 37（文章進 `/chat`）出貨當天說「我希望連來源也有支援直接對話功能」。
> 母設計＝[文章成為對話對象與 Canvas 編輯](2026-08-21-文章成為對話對象與Canvas編輯.md)（同一套機制，換一個資料來源）。

## 一、先接地：來源**現在就已經**進得了對話

`src/knowfield/web/app.py:262`：

```python
sources = list(_chat_search(q)) + _chat_corpus(message)
```

`_chat_corpus`（`:196`）的 docstring：「檢索使用者收進的相關資料，當『你收藏的』證言（spec 029）」。

⇒ 你收進的來源**一直都在被撒網**。所以本階段的價值不能寫成「讓來源能進對話」——那是既有的。

**真正的差別一句話：從「它猜哪些相關」變成「我說就是這一份」。**

| | 撒網（現況） | 帶著這份聊（本階段） |
|---|---|---|
| 選誰 | 檢索依你這句話的相似度挑 | 你指定 |
| 範圍 | 片段，可能漏 | 整份在視野裡 |
| 失敗方式 | **沉默**——它沒撈到，你不會知道 | 沒有這種失敗 |

⚠️ 「沉默地漏掉」是撒網真正的成本，而不是「不夠準」。**這一條要寫進驗收**，
否則做完會覺得「跟原本好像差不多」。

## 二、三個必須先定的東西

### ① ⚠️ 餵原文，還是餵你正在看的譯文？（來源獨有，文章沒這一層）

儲存層是原文（spec 037 FR-004 逐字保留鐵律），但你眼前可能是 s2t 繁體、或整份翻譯的繁中（spec 038/039）。

**決定：餵原文，並在脈絡裡告訴模型「使用者讀的是譯文」。**

理由不是「原文為真相」這句口號，是一個具體 payoff——你說「這段 residual 的說法怪怪的」時：

- 餵譯文 → 模型跟你一起在**翻譯錯誤**上打轉，兩個人一起錯
- 餵原文 → 模型能說「原文寫的是 X，中文翻成 Y 有點失真」

＋ 譯文本身是 AI 產物，餵回去是那條回灌線的縮小版。**餵原文反而讓它替你抓翻譯的錯。**

ⓘ 代價要記著：使用者引用「第三段那句」時，模型看到的字面與畫面不同 ⇒
脈絡裡必須明講這件事，模型才會主動做對應。這是**已知限制**，不假裝沒有。

### ② 長度：來源比文章大一個量級

`_ARTICLE_CAP = 6000`；實測 colah 那篇 20,771 字、Attention 那篇 37,691 字。

**決定：短的全文進；長的用既有檢索、但把範圍縮到這一份。**

- 不是新機制——`retrieve_corpus` 已經在了，加一個 url 過濾即可。
- 它同時解掉長度問題，又保住「不會漏到別份來源」的語意。
- ⚠️ **代價要講明**：問「這篇整體在講什麼」時塊檢索答不好 ⇒ 必須是**混合**，不是純檢索。
- **否決：直接截斷前 N 字。** 後半消失而使用者不知道——又一個沉默失敗。

### ③ ⚠️ 041 的閘門**不得照搬**

spec 041 FR-003 擋「冊封候選 MUST NOT 由文章原文直接生成」，理由是 **model collapse——文章是 AI 產物**。

來源不是。而且**從來源冊封本來就是既有的合法功能**（`/api/source/distill`，來源頁那顆「🎓 整理成核心理解」）。
照搬那道閘門等於白白閹掉一條本來就開著的路。

⇒ 這是 `experience.md`「**同一個機制換一個用途，判準要跟著換——不能整套照搬**」的又一個實例，
而且是**主動避開**、不是事後補救。

## 三、⚠️ 一個靜默的坑：雙重注入

來源被帶進對話之後，它**同時還在被撒網**。同一段文字可能注入兩次——
一次當「你帶的這份」、一次當檢索命中——而模型會把它當成**兩個獨立佐證**。

這種錯不報錯、畫面上也看不出來，只會讓答案的語氣比證據更有把握。
⇒ 要在寫的時候就去重，不能等發現。

## 四、形狀不用再糾正一次

階段 37 已經把形狀糾正到位（**五次**，見 [history/101](../history/101-文章當第一則-從掛在對話上改為開新對話.md)）：
**開新對話**、當**第一則**、`<details>` 比照章節、**無起手式、無額外控制項**。

本階段就是把同一套機制換一個資料來源，入口放 `/source` 頁、與 `/articles/:id` 那顆對稱。
⇒ **不得**藉這一刀重開形狀討論；沿用。
