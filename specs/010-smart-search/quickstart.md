# Quickstart：智慧搜尋（階段 9 增量 b）

前置：已完成階段 9（`/search` 可搜、可收進），Tavily 金鑰已設（真搜）或離線 stub。

## 1. 打 query 看整理
```
開 http://127.0.0.1:8000/search → 輸入「Multi Agent RL」→ 送出
```
預期：
- **頁面頂端**一段繁中「整理」重點，句中 `[1] [2]…` 是**上標連結**。
- 點某個 `[n]` → 平滑捲到下方**第 n 則結果卡**（高亮）。
- 下方結果**依相關度排序**（最相關在前）；每則仍有「收進」鈕。

## 2. 收進（人挑不變）
```
在某則結果按「收進」→ 到「知識庫」看到它 → 「問答」問得到
```
預期：只有按的那則成種子；整理與其他結果**不落庫**。

## 3. 降級（外部不穩仍可用）
- 某則內文抓不到：整理照出（該點用摘要），頁面不崩。
- 整理服務失敗／無金鑰：頂端顯示友善繁中「整理暫時無法產生」，**下方結果照常可收進**。

## 4. 離線可測
```
uv run pytest tests/unit/test_smart_search.py tests/contract/test_smart_search.py -q
```
預期：全綠、零外部呼叫（stub 全鏈）。全套 `uv run pytest` 不回歸（≥197）。
