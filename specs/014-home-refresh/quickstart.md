# Quickstart：首頁重新整理（階段 12）

## 1. 一鍵重整
```
開 http://127.0.0.1:8000/ → 按頂端「🔄 重新整理」
```
預期：系統從啟用中的來源重跑分診（抓最新→消化），完成後首頁顯示**剛產生的最新匯整**
（熱詞 chips 一併更新）。鈕旁有繁中提示「會抓最新並重新消化，需要一點時間」。

## 2. 舊匯整保留
- 重整多次：每次新增一份；首頁顯示最新，舊的仍在（流的紀錄）。

## 3. 缺漏/失敗友善
- 部分來源當日取不到：匯整照常產出、明確標示缺漏來源。
- 後端/來源整體失敗：頁面顯示友善繁中提示、不崩、不噴堆疊；既有匯整不受影響。

## 4. 離線可測
```
uv run pytest tests/contract/test_refresh.py -q
```
預期：全綠、零外部呼叫（注入 stub factory）。全套 `uv run pytest` 不回歸（≥243）。
