# CLI 契約：`ask`

## 語法
```
learnnews ask "<問題>" [--today] [--lang <語言>] [-k <取回數>]
```

| 參數 | 必填 | 預設 | 說明 |
|---|---|---|---|
| `question`（位置） | 是 | — | 一句自然語言問題 |
| `--today` | 否 | 關（累積全部） | 只查最近一份匯整 |
| `--lang` | 否 | 繁體中文 | 答案語言（跟隨既有語言設定） |
| `-k` | 否 | 6 | 取回條目數上限 |

## 行為

1. 由 `Config.from_env()` 組 embedder／answerer（有 api_key→OpenAI，否則離線 stub）。
2. `RagService.answer(question, Scope(today), k, lang)`：
   - 載 scope 語料 → 確保嵌入（批次補缺）→ 嵌問題 → cosine 排序 → 濾門檻 → top-k。
   - 空 → 印「沒有相關材料」（或空庫時「尚無匯整，請先執行 digest」）。
   - 非空 → 印答案（含 `[n]`），續印「來源：」清單（`[n] 標題 — 原文連結`）。

## 輸出（範例，非空）
```
<繁體中文答案，論點以 [1][2] 標註>

來源：
[1] <標題> — <url>
[2] <標題> — <url>
```

## 退出碼
| 情境 | 碼 | 輸出 |
|---|---|---|
| 正常（有答案或明說查無） | 0 | 如上／「沒有相關材料」 |
| 後端失敗（OpenAIError／隔離／逾時） | 1 | 友善繁中訊息，**無** traceback（FR-006） |
| 用法錯誤（缺問題） | 2 | argparse usage |

## 不變式（對映 FR）
- 答案只出自檢索到的來源；`sources` 由程式端從檢索集合生成（FR-003）。
- 查無相關**不呼叫合成後端、不產生內容/來源**（FR-004）。
- 面向使用者文字全繁中（FR-007）。
- 一次問答對外部 API 呼叫 = O(1)（嵌問題＋最多一次合成）；不重嵌語料（FR-009、SC-004）。
