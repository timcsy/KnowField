## User Scenarios & Testing *(mandatory)*

### User Story 1 - 對累積知識庫問答，答案可溯源 (Priority: P1)

使用者已用工具跑過多日匯整，材料累積在本機。某天沒時間逐則讀，直接下一句問題（例：
「最近 agent 記憶體有什麼進展？」），工具從**所有已落庫匯整**裡找相關條目，合成一段
繁中答案，且**每個論點都標明出自哪一則、附原文連結**，使用者能一眼跳回原文核對。

**Why this priority**: 這是本增量的核心價值——把「沒時間逐則讀」變成「問一句就懂、且能溯源」，
直接服務根公理（跟上趨勢的成本要極低）。單獨實作即為可用 MVP。

**Independent Test**: 種入幾則已知內容的匯整條目，問一個命中其中某則的問題，驗證答案內容
出自那些條目、且列出對應來源（title/url）；問一個語料裡有、措辭不同的問題也能命中。

**Acceptance Scenarios**:

1. **Given** 庫中有跨多日的匯整條目，**When** 問一個與某些條目相關的問題，**Then** 得到一段
   繁中答案，答案中每個論點皆可對應到至少一則來源，並列出這些來源的標題與原文連結。
2. **Given** 同上，**When** 問題用詞與原文不同但語義相關，**Then** 仍能檢索到相關條目（語義比對，
   非關鍵字精確匹配）。
3. **Given** 答案已產出，**When** 使用者檢視，**Then** 答案不含任何無來源的斷言（凡陳述皆有出處）。

---

### User Story 2 - 限定「今天」範圍問答 (Priority: P2)

使用者只想針對**當日最新匯整**問（「今天這批的重點是什麼？」），不希望被歷史材料稀釋。
加上 `--today` 即把檢索範圍限縮到最近一份匯整。

**Why this priority**: 「切穿今天這批」是使用者原始動機之一；與 P1 共用檢索管線，只多一個
範圍過濾，成本低、價值明確。

**Independent Test**: 種入「昨天」與「今天」兩份匯整；同一問題分別在預設與 `--today` 下問，
驗證預設會納入兩份、`--today` 只納入最近一份。

**Acceptance Scenarios**:

1. **Given** 庫中有多份不同日期的匯整，**When** 加 `--today` 問，**Then** 答案只根據最近一份
   匯整的條目，來源不含更早日期的條目。
2. **Given** 同上，**When** 不加 `--today`（預設），**Then** 檢索涵蓋所有已落庫匯整。

---

### User Story 3 - 誠實邊界：查無說無、失敗不炸 (Priority: P3)

當庫中沒有相關材料、或庫是空的、或外部後端（嵌入／合成）暫時失效時，工具要**誠實且穩健**：
明說「沒有相關材料」而非硬編一個答案；後端失敗時給友善繁中訊息而非噴出技術堆疊。

**Why this priority**: 這是原則 3（無來源不出貨）與工具可信度的底線。少了它，RAG 會用幻覺
污染使用者的判斷；但它依附於 P1 的管線，故列 P3。

**Independent Test**: (a) 對空庫或明顯無關問題問，驗證回「沒有相關材料」且不含編造內容；
(b) 令後端拋錯，驗證得到友善繁中訊息、程式正常結束、無堆疊輸出。

**Acceptance Scenarios**:

1. **Given** 庫為空或無條目與問題相關，**When** 問，**Then** 明確回覆「沒有相關材料」之類訊息，
   且**不產生任何編造的答案內容或來源**。
2. **Given** 外部後端（嵌入或合成）失敗，**When** 問，**Then** 顯示友善繁中錯誤訊息，指令正常
   結束，不輸出未處理的技術堆疊。

### Edge Cases

- **語料為空**（從未跑過匯整）：回「沒有相關材料／請先產生匯整」，不報錯。
- **問題與語料弱相關**（最佳匹配低於相關度門檻）：視為查無相關，明說，不硬答。
- **`--today` 但當日無匯整**：回「今天尚無匯整」。
- **既有匯整在本功能上線前產生、無對應嵌入**：需能被納入問答（補嵌或明示涵蓋範圍），
  不得靜默漏掉——避免「答得很篤定，其實漏了一半語料」。
- **答案語言**：跟隨既有語言設定（預設繁中）。

## Requirements *(mandatory)*

### Functional Requirements

- **FR-001**：系統 MUST 提供一個問答指令，接受一句自然語言問題，對**已落庫的匯整條目**
  （消化散文＋標題）檢索並回覆一段答案。
- **FR-002**：檢索 MUST 為**語義相關**（用詞不同但意思相關也能命中），非僅關鍵字精確匹配。
- **FR-003**：答案 MUST **只根據檢索到的語料**；每個論點 MUST 可對應到至少一則來源，並**列出
  來源的標題與原文連結**（原則 3 溯源；無來源的斷言不出貨）。
- **FR-004**：查無相關材料（含空庫、弱相關低於門檻）時，系統 MUST **明說沒有相關材料**，
  MUST NOT 產生編造的答案或來源。
- **FR-005**：使用者 MUST 能以 `--today` 把檢索範圍限縮到**最近一份匯整**；預設涵蓋**所有**
  已落庫匯整。
- **FR-006**：外部後端（嵌入／合成）失敗時，系統 MUST 在指令邊界攔成**友善繁中訊息**、正常
  結束，MUST NOT 輸出未處理的技術堆疊（experience 教訓 3、憲章原則 V）。
- **FR-007**：所有面向使用者文字 MUST 為**繁體中文**；答案語言跟隨既有語言設定（憲章原則 II）。
- **FR-008**：問答 MUST **複用既有核心**（既有的嵌入／合成後端、資料存取、指令框架），不重寫
  核心邏輯；亦 MUST 有**離線可跑**的後端組合，讓功能在無外部服務下可被完整測試（教訓 1）。
- **FR-009**：語料的嵌入 MUST 在**產生匯整時一次算好並留存**；問答時 MUST NOT 重新消化或
  重新嵌入整個語料（只需處理當下的問題），以維持互動級回應並避免對外部 API 過量呼叫
  （experience：批次＋不逐一呼叫）。
- **FR-010**：本功能上線前既有的匯整條目 MUST 能被問答涵蓋（透過補算嵌入或等價手段），
  不得因「沒有預存嵌入」而被靜默排除。

### Key Entities *(include if feature involves data)*

- **問題（Query）**：使用者輸入的一句自然語言問句，可帶「範圍」旗標（今天／累積）。
- **知識條目（Corpus Entry）**：一則已落庫的匯整條目，含消化散文、整理過標題、原文標題與
  連結、所屬匯整日期；是檢索與溯源的最小單位。
- **相關度（Relevance）**：問題與知識條目的語義接近程度；決定取哪些條目、以及是否「查無相關」。
- **答案（Answer）**：根據檢索條目合成的繁中回覆，附**被引用的來源清單**（標題＋原文連結）。

## Success Criteria *(mandatory)*

### Measurable Outcomes

- **SC-001**：對命中語料的問題，答案中**每一個陳述都能追溯到至少一則已落庫來源**（人工抽查
  一組問題，可溯源率 100%、無杜撰內容或來源）。
- **SC-002**：查無相關（空庫／無關問題）時，**100%** 回「沒有相關材料」，**0** 例編造答案。
- **SC-003**：範圍過濾正確——`--today` 的答案來源**只**含最近一份匯整；預設涵蓋全部匯整
  （以種入的多日語料驗證，正確率 100%）。
- **SC-004**：問答為互動級回應（不重跑消化、不重嵌語料）；一次問答對外部服務的呼叫次數
  與語料規模無關（不隨條目數線性增加）。
- **SC-005**：後端失敗時**100%** 呈現友善繁中訊息、無技術堆疊外洩。
- **SC-006**：面向使用者文字全繁中；功能可在**離線後端**下完整通過測試（零外部呼叫），且
  既有測試套件不回歸。

## Assumptions

- **語料來源**＝既有每日匯整的落庫條目（消化散文＋標題＋原文連結）；本增量**不**新增抓取、
  不做種子 ingest、不爬全文（那是階段 4 增量 2）。
- **檢索規模**：個人語料量級（數百～數千條目），採直接語義比對即可達互動級回應，**不需**
  專用向量資料庫（YAGNI）。取回條目數與相關度門檻採合理預設、可調。
- **「今天」的定義**＝最近一份匯整（代表當日分診結果）。
- **答案品質**：離線後端僅保證**流程正確可測**；答案的語義品質依賴真實嵌入／合成後端——
  離線比對已知會有語義碰撞（experience 教訓 4），故測試斷言用**實測會匹配**的字串，品質驗證
  另以真實後端抽查。
- **介面**：本增量為 **CLI 指令**（`ask`）；web 問答框為後續 fast-follow，範圍外。
- **開發**：TDD 強制（憲章原則 I）——先寫失敗測試再實作；契約測試用離線後端組合。
- **相依**：複用既有語言設定（`--lang`）、既有嵌入／合成後端工廠、既有資料存取與指令框架。
