# Quickstart：對話的「由來」存檔

## 前置
- 已跑過 spec 022 的 `/chat`（有對話可存）。（真跑）已設 LLM 金鑰生自動標題；離線走 stub。

## 驗證情境

### 1. 冊封時連同存成由來（FR-001/005/SC-001）
1. `/chat` 聊出一條重點 → 按「整理」→ 對某條按「存起來」時勾「連同這段對話存成由來」。
2. 到「根因」頁看那條核心理解 → 有「← 由來（對話）」→ 點開＝那段完整對話。

### 2. 獨立存探索（FR-002/003/SC-002）
- 對話中按「💾 存這段對話」→ 存整段、自動生一句「由來」標題 → 到「對話存檔」清單找得到、讀得到整段。

### 3. 唯讀、不入地基（FR-004/SC-003，硬原則）
- 存一段含發想/猜測的對話 → 開新對話 → AI **只**從已冊封核心理解往下推；那段存下的對話**不會**被當
  場脈絡注入（守衛測：新對話 system prompt 不含該對話內容）。

### 4. 人閘門＋友善（FR-006/007/SC-004）
- 不按就不存（不自動存全部）；自動標題失敗→退回首句/時間仍存成功；連著由來的根因被刪→對話仍在清單（獨立）。
