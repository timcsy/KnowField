# spec 071：跨 base 判準的收件匣（vision 階段 67）

## 為什麼

使用者有 **13 個 knowie base、1,337 條教訓**，而看不到複利：
「現在因為還沒整合，所以**看不到複利效應**，要開新專案還是要冷啟動。」

實測（2026-08-27，1,393 條 × `text-embedding-3-small`，只比跨 base）：
**跨 base 群 49 個／157 條**，跨 ≥3 個 base 的 **16 群**。

⚠️ 而最刺的三群，是 KnowField **今天才學會**、而別的 base **早就寫下來**的：

| 群 | |
|---|---|
| 警告不是實作 | `KnowField`（**今天 spec 064**）· `VizGPT` · `wewayfinders` |
| 量測工具會說謊 | `KnowField` · `VizGPT` · `semorphe` |
| 量了一件錯的事 | `VizGPT` · `semorphe` ← **正是這個 session 犯了四次的錯** |

⇒ **複利不是抽象的**：一整個 session 有好幾個小時在重新發現別的 base 已經寫下來的東西。

## 形狀：收件匣，不是資料庫

設計源逐字（`draft/2026-08-27-room與組織的AI-人的樹.md:132`）：

> **共享空間必須是收件匣，不是資料庫。** 共同儲存會違反「先各自隔離」
> ⇒ 它是**佇列**：東西停在那裡直到你**收進**自己的場。沒有共享狀態，只有傳輸中的訊息。

⚠️ **而那個佇列的資料結構全都在了**：`why_nodes.status = 'candidate'|'anointed'`、
`anoint_why_node()` 就是那道人閘門、`/api/roots` 已經回 `candidates`。
**缺的只有畫面**——`RootsPage` 完全沒渲染它們。

⇒ 這一刀因此比 draft 自己排的「A 唯讀索引」小得多：**不需要 clone、不需要 `base_id`**。

## FR

- **FR-001** `origin` 支援 `from:<base>`。⚠️ **借來的要標成借來的**——
  在這個場**真的撞到之前，它不算你自己撞出來的**。
- **FR-002** 匯入候選：吃群的清單（`knowie-xbase` 產出），落成 `status='candidate'`。
  ⚠️ **群的計算不在這一刀裡**（那是 skill；它跑在 base 所在的地方）。
- **FR-003** 理解頁畫出收件匣，每條顯示 **它跨哪幾個 base ＋ 群成員原文**。
  ⚠️ **給原文，不要給分數**——判準是「你能不能像肉眼校驗那樣判斷它」，
  而分數不可反駁（spec 065 判準①）。
- **FR-004** 逐條**冊封／略過**。⚠️ **沒有「全部收下」**，且**沒有那條 API**
  （沿用 spec 065／069：禁令做在結構上，並有測試掃路由表）。
- **FR-005** 略過的**不再出現**——否則每次匯入都要重看一遍。
- **FR-006** 冊封之後 `origin` **保留** `from:<base>`；冊封只改 `status`。
- **FR-007** 跨不了 `owner`／`persona`（沿用 `_own()` 那一份述詞，不另發明）。

## 驗收

1. 匯入 N 群 → 收件匣 N 條，每條看得出**跨哪幾個 base** 與**成員原文**
2. 冊封一條 → 進理解清單 · `origin='from:<base>'` · ⚠️ **進得了檢索語料**
   （寫進去但不在場裡，不會報錯——spec 062 驗收 3 同一條）
3. ⚠️ 略過之後重新匯入同一份，那一條**不再出現**
4. ⚠️ 路由表裡沒有任何一次收多條的路徑
5. 換一個 persona → 看不到、也搜不到
6. 實跑：把今天算出來的 49 群匯入正式庫，逐群審過一輪

## Out of scope

git clone · `base_id` · 雙模式 UI · 符號索引 · agent runtime ·
**反證回饋**（要先有 borrowed 才談得上）· **群的計算本身**

## ⚠️ 兩個要寫進實作的判準

- **相似度是篩子，不是判準。** 0.62 把 1,393² 降到 49 群——**十分鐘看得完**。
  所以介面是**複審佇列**，不是自動化。
- **recall 有限。** 那對 0.581 的真配對（`沒有東西會叫的失敗` ↔ `沉默的失敗不會自己現形`）
  **任何合理門檻都抓不到** ⇒ 介面不該讓它看起來像全部。
