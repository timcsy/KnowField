# Quickstart：反逢迎的「值不值得」副手

## 前置
- （真跑）已設搜尋 API 金鑰（Tavily 相容）＋ LLM 後端；離線則走 stub。
- （手機）ops：`cloudflared tunnel --url http://localhost:8000` → 手機開 tunnel 網址（非本 spec 功能）。

## 驗證情境

### 1. 丟一個名字 → 反逢迎綜合（FR-001/003/004/005/SC-001）
1. 開 `/worth`，貼「Claude Opus 5」，送出。
2. 得綜合：**官方說法／獨立評測／真實用戶心得分開**、明說炒作/缺點、有引用連結、給「值不值得你＋怎麼用」。

### 2. 收內容口——只給內文/抓不到的網址也能跑（FR-002/007/SC-002）
- 只貼一段**你在 Threads 看到的內文**（無網址）→ 照樣認出主題、撒網、回綜合。
- 給一個**伺服器抓不到的網址**（403/牆內）→ 友善退回、改用名字/標題續跑、**頁面不崩**。

### 3. 獵心得 query（FR-003/SC-003）
- 撒網用多角度查詢（心得/評價、vs 缺點、值得嗎、怎麼用），非查通用名；某面向查無 → 誠實說沒搜到。

### 4. 失敗/空友善（FR-008/SC-004）
- 搜尋/綜合失敗 → 友善繁中、頁不崩。撈不到心得 → 「這東西太新/資料太少」。

### 5. 手機友善（SC-004）
- `/worth` 頁 RWD、手機可操作；收內容口讓手機送得進來。
