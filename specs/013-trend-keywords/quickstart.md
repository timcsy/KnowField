# Quickstart：趨勢讀數（階段 11）

前置：已有幾份每日匯整（`digest`）。

## 1. 首頁看「現在在紅什麼」
```
uv run learnnews digest        # 產幾份匯整（不同日）
開 http://127.0.0.1:8000/
```
預期：首頁**頂端**出現一排 **6–8 個熱詞 chips**（源自最近幾份匯整標題的高頻主題詞），
標題描述性（「🔥 今日高頻」），**不必你先輸入任何關鍵字**。

## 2. 點熱詞深挖（溯源）
```
點任一熱詞 chip
```
預期：進入 `/pull?topic=<熱詞>` 主題深挖，看到跨來源、可回溯原文的真實材料——證明熱詞
**背後是真實內容**。

## 3. 沒東西不擺空殼
- 全新（無匯整）或算不出有意義的詞：首頁**不顯示**熱詞區塊，其餘照常。

## 4. 離線可測
```
uv run pytest tests/unit/test_trend_keywords.py tests/contract/test_trend.py -q
```
預期：全綠、零外部呼叫（純統計）。全套 `uv run pytest` 不回歸（≥234）。
