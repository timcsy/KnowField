# Quickstart：根因萃取（階段 10）

前置：知識庫已有種子（`ingest` 或 `/search` 收進）。

## 1. 對種子萃取根因
```
開 /library → 某則種子按「萃取根因」
```
預期：導到 `/roots`，出現一個**候選根因**：一段主張＋**明標「AI 推斷（據 [來源]）」**＋
**試金石逐條**（哪條過/沒過）＋霧詞旗標＋證據連結。離線 stub 時試金石全標「待驗」。

## 2. 冊封（人挑）
```
在候選卡按「冊封」（可先編輯文字）→ 轉「已冊封」；或按「退回」刪除
```
預期：只有你冊封的成正式吸引子；沒點頭的仍是候選、不影響問答。

## 3. 閉環：冊封的根因讓問答更透
```
冊封一個根因 → 到 /ask 問相關問題
```
預期：**檢索得到那個根因**、可回溯其證據；且它**份量高於解說文與快訊**（重吸引子）。

## 4. 離線可測
```
uv run pytest tests/unit/test_rootcause.py tests/contract/test_root_cause.py -q
```
預期：全綠、零外部呼叫。全套 `uv run pytest` 不回歸（≥219）。
