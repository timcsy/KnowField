# CLI 契約：`ingest`

## 語法
```
knowfield ingest <ref> [--explainer]
```

| 參數 | 必填 | 預設 | 說明 |
|---|---|---|---|
| `ref`（位置） | 是 | — | arXiv ID（`2407.12345`／`arXiv:…`／`…/abs/…`）或文章 URL |
| `--explainer` | 否 | 關 | 標為**解說文**（高品質類，檢索權重加成） |

## 行為
1. 正規化 `ref`；查種子容器是否已存 → **已存**則印「已在庫：<標題>」、退出碼 0，不重插。
2. 抓取單篇（arXiv id_list／URL 淺抽）→ 消化 → 嵌入 → 存為種子。
3. 成功印「已收進知識庫：<標題>（<類型>）」＋原文連結。
4. 種子存入後，`ask`（CLI＋web）即可檢索到。

## 輸出（範例）
```
✅ 已收進知識庫：Attention Is All You Need（解說文）
   原文：https://arxiv.org/abs/1706.03762
```

## 退出碼
| 情境 | 碼 | 輸出 |
|---|---|---|
| 成功 / 已在庫 | 0 | 如上 |
| 抓取/解析/後端失敗 | 1 | 友善繁中訊息，**無** traceback，**未寫入半殘種子**（FR-006） |
| 用法錯誤（缺 ref） | 2 | argparse usage |

## 不變式（對映 FR）
- 種子必掛原文連結（FR-003）；失敗不半殘入庫（FR-006）。
- 同篇多寫法／重複 ingest 不製造重複（FR-004/007）。
- 使用者指定才收，工具不自動認 canon（FR-008）。
- 解說文檢索權重＞一般（FR-005）；相關度門檻仍用原始 cosine 把關。
- 離線可測（http_get 可注入假來源，零外部呼叫）（FR-009）。
