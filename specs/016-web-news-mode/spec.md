# 規格：web 活水 news 模式（只回近期新聞）

**功能**：LearnNews 路線圖階段 13 增量 b
**分支／目錄**：`specs/016-web-news-mode/`
**建立日期**：2026-07-26

## 摘要

階段 13（live web 活水）已把開放網路搜尋接進 digest，但實跑發現：用**通用查詢＋一般搜尋**，
開放網路回的多是**常青 SEO 清單文**（「Top 7 open source LLMs 2026」這種），**不是「剛炸的
新聞」**（Opus 5 剛發布這種）。本增量讓 web 活水走 **「news 模式」**：向搜尋服務**請求近期新聞**
（限定新聞主題＋時間範圍），digest 的 web 材料變成**有時效的新聞**、而非 SEO 常青內容。

手動搜尋（`/search`）**維持一般搜尋不變**——一般搜尋要廣、不該只限新聞。

## 使用者情境與測試

### 主要使用者故事

**US1（P1）——web 活水撈到的是近期新聞**
作為想追剛紅的使用者，我希望 digest 裡的開放網路材料是**這陣子的新聞**（新模型發布、產品
上線），而不是搜尋引擎優化出來的常青清單文。

- **驗收情境**：
  1. **Given** 我啟用 web 活水源，**When** 產生匯整，**Then** 開放網路帶進的材料是**限定近期
     新聞**（依設定的時間範圍，如一週內），而非不限時間的一般搜尋結果。

**US2（P1）——手動搜尋維持一般搜尋**
作為使用者，我用 `/search` 手動搜某主題時，希望**涵蓋面廣**（不只新聞，也含教學、文件、
討論），不被限制成只回新聞。

- **驗收情境**：
  1. **Given** 我用 `/search` 搜一個主題，**When** 送出，**Then** 結果**維持一般搜尋**（不限新聞、
     不限時間），與現況一致。

**US3（P2）——時間範圍可調**
作為使用者，我可以調 web 活水的新聞時間範圍（如一天／一週／一月），控制「多新才算數」。

- **驗收情境**：
  1. **Given** 我把時間範圍設為「一天」，**When** 產生匯整，**Then** web 活水只撈**當日**新聞。

### 邊界情況

- **搜尋服務不支援 news 參數**：多回一般結果（不因多送參數而失敗）——寬鬆相容。
- **news 搜尋失敗**：沿用既有缺漏機制（匯整照常、標缺漏），與現況一致。
- **離線（測試）**：離線後端忽略 news／時間範圍，行為不變、可測。

## 需求（功能）

- **FR-001**：digest 的開放網路活水**必須以「近期新聞」方式搜尋**（限定新聞主題＋時間範圍），
  使帶進匯整的 web 材料是有時效的新聞而非常青 SEO 內容。
- **FR-002**：手動搜尋（`/search`）**必須維持一般搜尋**（不限新聞、不限時間），行為與現況一致。
- **FR-003**：新聞時間範圍**必須可設定**（如一天／一週／一月），預設為一週。
- **FR-004**：news 模式為**向後相容的擴充**——搜尋能力預設仍是一般搜尋；只有 web 活水明確以
  news 模式呼叫。既有行為與測試**不得受影響**。
- **FR-005**：web 活水的 news 搜尋**必須可離線測試**（可插拔、零外部呼叫可通過契約測試），且
  可驗證確實以「新聞主題＋時間範圍」發出請求。
- **FR-006**：news 搜尋**失敗**時，沿用既有缺漏機制（匯整照常、標缺漏來源）。
- **FR-007**：所有面向使用者文字**必須為繁體中文**；**不得新增第三方相依**。

### 明確排除（範圍外，防蔓延）

- **把 `/search` 手動搜尋改成 news 模式**（維持一般搜尋）。
- **客端二次日期過濾**（信任搜尋服務的時間範圍；自訂日期過濾列後續）。
- **興趣驅動查詢**（另後續）。
- **多搜尋供應商的 news 參數對映**（先對現用服務；其他供應商日後）。
- **竄升／成核**。

## 關鍵實體

- **搜尋模式**：一般（廣、預設，供 `/search`）／新聞（近期、供 web 活水）。
- **時間範圍**：新聞的新鮮度窗（一天／一週／一月），可設定。

## 假設

- 沿用既有可插拔搜尋後端（一般搜尋已可用）；news 模式是其可選擴充。
- 現用搜尋服務支援「新聞主題＋時間範圍」參數；不支援者寬鬆退回一般結果。
- 預設時間範圍一週（合理的「剛紅」窗）。

## 成功標準（可驗，技術中立）

- **SC-001**：啟用 web 活水後，帶進匯整的開放網路材料是**近期新聞**（依時間範圍），SEO 常青
  清單文明顯減少。
- **SC-002**：`/search` 手動搜尋**維持一般搜尋**、涵蓋面不變。
- **SC-003**：時間範圍**可調**並生效。
- **SC-004**：**向後相容**——既有搜尋行為與 260 項測試不回歸；離線可測、零外部呼叫。
- **SC-005**：news 搜尋失敗沿用缺漏機制、匯整照常。
- **SC-006**：**`/search` 未被改成 news 模式、無客端日期過濾、無興趣驅動查詢**（範圍守住）。
