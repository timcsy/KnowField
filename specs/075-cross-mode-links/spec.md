# spec 075：讀別人的文件時，你自己的場浮出來——**量測否決，不建**

> 狀態：⚠️ **不建（2026-08-27）**。原因不是做不出來，是**量出來沒有那個重疊**。
> 這一份保留為**當時的量測**：條件變了要重量，別憑印象重開。

## 原本要做什麼

draft §七 列的雙模式**第二個代價**：

> 「**撞見會消失**（分模式＝分場）｜⛓「通往哪裡」要能指到另一邊」

⇒ 在開發模式讀別人的一份文件時，把**你自己場裡相關的理解**顯示在旁邊。
實作本來很便宜：`retrieve_corpus` 現成、向量現成、方向也不違反 spec 074 那道膜
（是**你的**知識浮到別人文件旁邊，不是別人的進你的語料）。

## ⚠️ 而量測否決了它

40 份外部文件（VizGPT／knowie，排除 KnowField 自己）對場裡 80 條已冊封理解，
各自取**最高**相似度：

```
最高 0.560 · 中位 0.463 · 最低 0.367      ← 整個範圍只有 0.19 寬，**沒有斷點**
門檻 0.45 → 23/40 份會顯示東西（幾乎都是雜訊）
門檻 0.50 → 15/40
門檻 0.55 →  2/40
門檻 0.60 →  0/40
```

**沒有一個門檻是對的。** 而原因不是門檻：

| | 內容 |
|---|---|
| 場（80 條理解） | Transformer 層／表示學習／粗到細⋯ **AI 與 ML** |
| 那三個 base | 測試怎麼假綠、判準怎麼寫⋯ **軟體工程** |

⚠️ 最直接的證據：**三份毫不相干的文件，最相關的都是同一條**
「Transformer 層＝置換等變集合函數 ρ(Σφ)⋯」。那是嵌入空間的**雜訊底線**，不是相關性。

## 判準：**先量重疊，再蓋橋**

一座橋的價值等於兩岸真的有東西要過去。這裡兩岸講的不是同一件事
⇒ 蓋了只會**永遠顯示三條無關的**，或**永遠顯示「沒有相關的」**——兩種都會被學會忽略。

⚠️ 而這件事**只有量了才知道**：設計文件（draft §七）寫得完全合理，
實作也便宜，前提也全部成立。**唯一不成立的是那個假設本身**。

## 什麼時候該重量

**當場裡開始有工程判準的時候**（例如那 3 條借來的判準被收下、或你開始用 KnowField
記軟體工程的理解）。⇒ 條件是**兩岸的內容重疊**，不是時間。

## ⓘ 順帶量到的

`retrieve_corpus` 的預設 `min_score=0.10` 是給「聊天時撒網」用的——那裡寧可多給。
拿它當「有沒有真的相關」的門檻會**永遠有三條**，而永遠有三條的東西沒有人會看第二次。
