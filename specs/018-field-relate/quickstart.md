# Quickstart：場對新材料做工（階段 15）

前置：知識庫已有**冊封的根因**（`/roots` 冊封過）或**種子**（`/library`）。

## 1. 關聯一則材料到你的場
```
開 /library → 某則種子按「🧭 關聯到我的場」
```
預期：得到它與你**最相關的根因/種子**的關係——
- **延伸**你的根因 X（順著它、補強）
- **牴觸**你冊封的 Y（← Google 不會告訴你「這跟你以為的相反」）
- **無明顯關聯**（誠實，不硬掰）
- **成核候選**（離你所有吸引子都遠＝新地基？建議萃取根因/收進）
每個關係附一句 grounded 理由、連到那個根因可核對。

## 2. 場不自動改
- 就算判「牴觸」，系統**只顯示、不自動退你的根因**——由你決定要不要據此動場（原則 5）。

## 3. 場空/失敗友善
- 還沒冊封任何根因/種子 → 提示「先冊封一些」。判關係服務失敗 → 友善繁中、不崩。

## 4. 離線可測
```
uv run pytest tests/unit/test_field_relate.py tests/contract/test_field_relate_web.py -q
```
預期：全綠、零外部呼叫（stub judge＋HashingEmbedder）。全套不回歸（≥274）。
