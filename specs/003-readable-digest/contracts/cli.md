# CLI 契約：可讀文章式消化（升級 digest／pull 輸出）

本階段**不新增指令**，而是升級 `digest`／`pull` 的輸出（摘要 → 散文文章＋圖），並加旗標。
測試以 `tests/contract/` 驗證。輸出繁中；後端/抓圖失敗優雅降級、不炸（FR-011、原則 V）。

## `digest` / `pull` 的輸出升級
- **預設**：每則產出**可讀散文文章**（取代「一句定位」），附一鍵原文；有原文圖則內嵌。
- **新增旗標**：
  - `--ai-image`：無原文圖時允許產生 AI 示意圖（預設關；產生者必標「AI 示意・非原文」）。
  - `--raw` / `--no-summary`：純原礦（僅標題＋來源＋連結，不生成文字或圖）——**沿用不變**。
- **格式**：`--format markdown` 內嵌圖（`![原文圖](url)`／`![AI 示意・非原文](url)`）；
  `terminal` 以「圖：<url>（原文／AI 示意）」一行呈現。

## 契約測試
- **散文**：預設輸出每則為連貫散文（非列點）＋一鍵原文連結（FR-001/004）。
- **忠實**：以「原文只有標題、無數據」的樣本 → 散文不出現捏造數據（FR-002，stub 驗證行為）。
- **不下結論**：散文不含工具結論式判斷（FR-003，stub 固定不產結論）。
- **原文圖**：樣本含原文圖 → 文章帶該圖並標為原文（FR-006）。
- **AI 圖標示**：`--ai-image` 且無原文圖 → 附 AI 圖且**標「AI 示意・非原文」**（FR-007/SC-005）。
- **--raw**：純原礦、無散文無圖、未呼叫生成後端（FR-008/SC-006）。
- **降級**：注入散文後端失敗 → 該則退精簡（標 degraded）、整體退出碼 0、不炸（FR-011/SC-007）。
- **推拉皆套用**：digest 與 pull 都走散文路徑（FR-009）。

## 抓圖 adapter 契約（`media/figure_extract.py`）
- 輸入一則 Item（含來源類型／原文連結／description）→ 回傳 Figure(原文) 或 None。
- **契約**：取不到圖 MUST 回 None（不拋例外、不阻塞）；回傳的圖 URL 非空。
- 測試以錄製的 RSS／arXiv HTML 樣本驗證解析；不打真實網路。
