# Quickstart：場驅動來源推薦

## 前置
- （場驅動排序要有效果）已冊封若干種子（`/ingest`）或根因（`/roots`）。
- （真跑）已設搜尋 API 金鑰（Tavily 相容）；離線則走 stub。

## 驗證情境

### 1. 一動作找出可訂新來源（FR-001/002/003）
1. 開 `/sources`，按「🔎 幫我找新來源」。
2. 得候選清單：每項有網域＋**確認活著的 feed**＋推薦理由。
3. 死/幻覺 feed 不在清單；沒 RSS 的候選標「無 RSS」（不報錯）。

### 2. 場驅動排序（FR-005/SC-002）
- 與你冊封的種子/根因語意相近的候選排最前；未冊封任何種子/根因時仍出清單（退回「有活 feed ＞ 跨清單重複」）。

### 3. 人訂閱才進名冊（FR-006/SC-004）
- 不按任何「訂閱」→ 名冊不變。
- 對一項按「訂閱」→ 走既有訂閱流進名冊，下次匯整帶入。
- 每日匯整照跑**不**自動觸發推薦。

### 4. 失敗/空友善（FR-008/SC-005）
- 搜尋或抓 feed 失敗 → 友善繁中、頁不崩。
- 撈不到可訂候選 → 「這次沒找到可訂的新來源」。


退回、路由 opt-in／訂閱複用 `/sources/add`／失敗友善／空結果。
