# spec 061：對話 → 互動

## 為什麼

使用者裁決（2026-08-26）：

> 我想要把「對話」改名為「互動」，並且我認為互動不只可以與AI互動，也可以與其他使用者互動

這不是換皮。「對話」這個詞把這一層綁死在**你與 AI 的來回**上，而路線圖上那三塊
（人自己寫理解／多方互動／論壇）全都需要這一層裝**別的東西**：別人的回覆、
非同步的討論串、你自己寫下的一段。名字先鬆開，那些才裝得進來。

⇒ 所以改的是**實體名**，不是所有出現過「對話」的地方。

## 範圍：三種「對話」不能改

「對話」和 spec 053 的「文章」是同一族——**一個詞同時是實體名和普通名詞**。
全域取代會把後面兩種一起掃掉，而且**不會有任何測試變紅**。

| # | 種類 | 例 | 為什麼不能改 |
|---|---|---|---|
| ① | prompt 裡指「這一段來回」 | `_DISTILL`「把以下對話裡…」 | AI 跟你的來回**本來就是對話**。改成「互動」只讓 LLM 更難懂，且不會出錯 |
| ② | 外部意義 | 登入頁「文章、論文、對話」 | 那是**別人的東西**，不是我們的實體。使用者收進來的從來不是別人的互動 |
| ③ | 動作 | 「接著聊」「對話串流失敗」 | 動作保留。實體名改，動作不改 |

另外**不改**（沿用 spec 053 的先例）：
- 程式識別字（`conversations` 表、`/api/conversations`、`conversation_id`）——改了要動 DB
- 註解與 spec／history 記錄——那是**當時**的用詞，改掉等於竄改歷史

## FR

- **FR-001** 使用者看得見的實體名一律「互動」：側欄入口、清單頁標題、`＋ 新互動`、
  空狀態、未命名占位、封存／溯源提示、種類標籤。
- **FR-002** ①②③ 三類逐字保留。
- **FR-003** ⚠️ **不能改一半**——`找不到那段對話` 留著而旁邊寫「互動」，比全部不改更難讀。

## 驗收

- `tests/unit/test_vocabulary_interaction.py` 全綠（正反兩面都測：該改的改了、不該改的沒動）
- 前端建置過、既有測試不變紅
- 實跑：側欄／互動頁／領域頁的標籤都是「互動」，登入頁那句仍是「文章、論文、對話」
